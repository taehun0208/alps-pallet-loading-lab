# 컨베이어 연장과 불량 전용 팔레트 · v27

## 조작

1. 적재 알고리즘 1대 / 확장성 탭의 **벨트 추가 길이 · 양 끝 mm**를 수정하고 **조건 적용 · 바로 재실행**을 누릅니다.
2. 기본값은 각 끝 1500 mm, 설정 범위는 각 끝 0–4000 mm 정수입니다. 1대 직선 벨트는 기존 4600 mm에서 기본 7600 mm가 됩니다. 작업셀과 집기 구역, 벨트 속도, 정상 팔레트 규격은 유지합니다. 속도 고정이므로 끝단 배출까지 걸리는 시간은 늘어납니다.
3. **찌그러짐 발생률**을 설정합니다. 기존 합성 스캐너가 편차 8 mm 이상의 박스를 불량 판정하면 정상 적재와 분리합니다.
4. **불량 팔레트 보기**로 격리 구역을 확대합니다. 팔레트는 불량이 없을 때에도 빈 상태로 표시합니다.

## 배치와 모델 범위

- `relay/rejectPallet.ts`는 불량 박스 각각의 ID와 치수를 보존하는 결정론적 바닥 선반 배치입니다. 간격 20 mm, 수직 적층 없음. 찌그러진 박스에는 다른 박스의 상부하중을 주지 않습니다.
- 바닥 공간이 부족하면 다음 불량 팔레트를 추가합니다. 기존 박스는 다시 이동하지 않습니다. 팔레트 규격은 정상 팔레트와 동일하고 현장 면적·가용 팔레트 수의 상한은 아직 모델링하지 않습니다.
- 팔레트보다 큰 박스는 별도 대형물 대기로 사유와 수량을 표시합니다. 축소하거나 정상 적재 수량에 포함하지 않습니다.
- 3D 메시에는 기존 눌림 형상을 적용합니다. 모든 격리 박스를 개별 표시하고 정상 적재 누계와 분리합니다.
- 스캐너에서 예약된 불량 팔레트 위치로 상승·이송·하강 애니메이션을 제공합니다. 기존 1.2초 분리 시간의 시각적/기하학적 모델이며 실제 구동기·로봇 역기구학·공장 시설 충돌·재질 강도 검증은 아닙니다.
- JSON 내보내기에 격리 완료 박스의 팔레트별 위치와 규격 초과 사유를 추가했습니다.
- `conveyorExtensionMm`을 생략하면 기존 벨트 길이가 그대로 재현됩니다.

## 검증

- 관련 8개 테스트 파일: 56개 통과. 신규 6개는 길이·범위, 집기 위치 보존, 불량 8개 개별 배치와 수량 보존, 충돌/경계/바닥 배치, 이전 위치 유지와 추가 팔레트, 규격 초과, 분리 이동 끝점을 검사합니다.
- TypeScript 검사와 Vite 프로덕션 빌드 통과.
- 실제 브라우저: 기본 7600 mm와 변경 후 8600 mm 확인. 시드 42, 입력 8개, 찌그러짐 100%, 16배 재생에서 39.0초 시뮬레이션 시간에 불량 8개 전부 개별 격리, 정상 적재 0개, 끝단 배출 0개, 수량 보존, 브라우저 콘솔 오류 0건을 확인했습니다.
