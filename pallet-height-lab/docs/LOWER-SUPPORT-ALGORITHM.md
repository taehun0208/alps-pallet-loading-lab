# 큰 박스 우선 · 아랫단 기준 하중 중심

2026-10-04. 모든 입력 재고를 실제로 꺼낼 수 있는 재고 선택 모드의 순서와 위치 평가를 보완했습니다. AI·학습·외부 추론 없이 기하 후보, 정적 평형, 평가 함수로 동작합니다. 치수·재질을 팔레트에 맞게 바꾸지 않습니다.

## 순서와 위치

1. 남은 모든 종류의 현재 배치 가능성을 검사합니다. 지지율 95%, 돌출 0mm, 충돌·높이·박스별 허용 하중·누적 반력·독립 기둥 조건을 통과한 종류만 비교합니다.
2. **바닥 면적 내림차순 → 부피 내림차순**으로 큰 박스를 먼저 선택합니다. 높이만 큰 박스를 넓은 받침으로 간주하지 않습니다. 크기는 작은 점수 보상이 아니라 종류 선택의 우선순위입니다. 큰 박스가 현재 불안정하면 보류하고 다음 가능한 종류를 검사합니다.
3. 모서리 정렬 후보에 **받침 중앙**과 **기존 하중의 치우침을 상쇄하는 위치**를 추가합니다. 받침 안으로 위치를 제한하고 실제 착지 높이를 계산합니다. 후보 예산 안에서 이 위치도 보존합니다.
4. 종류별 사전 후보 최대 16개, 크기 우선 상위 3종의 상세 후보 최대 24개를 검사합니다. Greedy는 아랫단 중심 치우침·재질 강도·높이·잔량 공간·받침 기회 등의 합산 점수로 위치를 고릅니다. 기본 배치는 잔량 적합 비중, 낮은 높이, 아랫단 치우침, y/x 순서입니다. Rollout은 최대 6개 후보의 후속 재고 선택을 최대 2단계 확인합니다.
5. 확정 전에 전체 적재의 반력과 모든 하부 하중을 다시 검사합니다. 확정한 ID 하나만 소비하며, 다음 단계에서도 보류 종류를 재검사합니다.

## 아랫단 하중 중심

각 박스의 자체 중심은 균일한 내부 질량을 가정한 기하 중심입니다. 위에서 전달되는 수직 하중은 접촉면의 압축 반력 비율과 작용점으로 나눕니다. 각 받침에서 자체 중량과 전달된 상부 하중을 합산합니다.

`누적 중량 M = 자체 중량 + 전달된 상부 하중`

`하중 중심 x = (자체 중량 × 자체 중심 x + Σ 전달 하중 × 작용점 x) / M`

y도 같습니다. 모든 접촉에서 수직 힘과 x/y 모멘트를 보존하며 음수 반력은 허용하지 않습니다. 여러 받침에 걸친 박스의 전체 무게나 중심을 각 받침에 중복 배정하지 않습니다. **여기의 x/y는 그 받침에 전달되는 합력 중심**입니다. 공유 지지가 있는 경우 특정 하부의 고유한 하위 트리 질량 중심과 동일하다고 주장하지 않습니다.

받침 기준점은 실제 접촉 영역의 볼록껍질 면적 중심입니다. 바닥 박스는 자신의 바닥 면을 사용합니다. 경계까지의 최단 거리에서 기존 최소 여유와 횡가속도 가정에 따른 필요 여유를 뺀 값이 전도 여유입니다. 위에 박스를 더 올릴 때도 모든 아래 접촉면에서 재계산합니다. 높이에 사용한 전달 질량의 z는 반력 비율로 분배한 근사입니다.

아랫단 치우침 지수는 접촉면 중심에서의 x/y 편차를 각각 반폭/반깊이로 나눈 최댓값입니다. 상부 하중을 받는 접촉면들의 최악값 75%와 누적 중량으로 가중한 평균 25%를 합칩니다. 이 평균은 여러 층의 **위험 평가**이며, 전체 물리 질량을 합산하는 식이 아닙니다. Stock 후보에는 `-2 × (균형 가중치 + 안정성 가중치) × 치우침 지수`를 더합니다. 기본 가중치에서는 `-72 × 지수`입니다. 전체 팔레트 사분면 균형과 별도 점수로 표시합니다.

상쇄 후보는 새 상자 중량 m일 때 `새 중심 x = (받침 중심 x × (M+m) − 기존 x 모멘트) / m`으로 얻습니다. 직접 전달되는 경우의 검색 힌트이며 공유 지지·장애물에서는 정확한 해가 아닐 수 있습니다. 매 후보를 실제 접촉·반력으로 다시 검증합니다.

## 먼저 시험한 입력

- 전체 팔레트 중심이 정확히 중앙이어도 좌우의 독립 아랫단이 각각 치우친 입력: 두 하부의 0.3125 치우침을 검출했습니다.
- 하나의 상자가 두 받침에 걸치고 그 위에 편심 중량을 올린 입력: 바닥 누적 하중의 합과 수평 모멘트가 원래 전체 질량과 일치했습니다.
- 400×400×100mm 받침 위에 200×200×100mm 상자를 한쪽에 올린 입력: 세 정책 모두 다음 상자를 반대편 `(200,100,100)`에 놓아 하부 중심을 `(200,200)`으로 맞췄습니다.
- 작은 박스의 높이 점수가 더 좋아도 넓은 박스를 먼저 선택하며, 면적 동률은 부피로 결정합니다. 더 큰 불안정한 긴 박스는 보류했습니다. 약한 플라스틱보다 입력 강도가 높은 종이 받침을 쓰는 기존 검사도 통과했습니다.
