# 무작위 배치 기준선

`알고리즘 비교` → `같은 입력으로 비교`를 누르면 기존 방식에 `무작위 배치`가 함께 실행됩니다. 재고 선택은 기존 3개 + 무작위, 순차 투입은 기존 6개 + 무작위입니다. 기존 적재 실험의 선택 메뉴에서도 사용할 수 있습니다.

## 정의와 제한

- 기존 경계 기반 후보 생성과 후보 개수 제한을 재사용합니다. 현재 유효한 후보 중 균등 무작위로 위치와 허용 자세를 선택합니다. 연속 XYZ 공간 전체에 대한 균등 추첨은 아닙니다.
- 평가 점수, 잔량 예약, rollout으로 후보 순위를 결정하지 않습니다. 기존 후보 진단 특징·점수 계산은 유지되며 선택에는 사용되지 않습니다. 그러므로 계산시간을 순수 난수 추첨 시간으로 해석하지 않습니다.
- 경계, 겹침, 지지, 무게중심, 하중, 허용 회전과 설정된 로봇 경로 제약은 그대로 검사하고, 배치 확정 직전에도 재검사합니다. 이상적 로봇 모드의 접근성은 기존처럼 미평가입니다.
- 순차 투입은 현재 도착한 박스만 사용합니다. 재고 선택은 현재 선택 가능한 개별 박스를 무작위로 섞고 배치 가능한 첫 박스를 사용합니다. 이미 보류한 박스의 복귀 위치는 보존하며 새 임시 보류 최적화를 수행하지 않습니다.
- `설정 · 데이터`의 계획 난수 시드와 현재 단계로 난수를 생성합니다. 실행 ID, 평가 가중치와 숨겨진 미래 입고는 선택 난수에 사용하지 않습니다. 반복 비교의 입고 시드는 기존대로 증가하고, 계획 시드는 고정됩니다.
- 기존 알고리즘 구현은 보존했습니다. `comparison.ts`의 목록을 UI와 Worker가 함께 사용합니다. 결과 표·3D·점선 높이 그래프·CSV·JSON에 포함됩니다.

## 실제 검증 (2026-10-09)

- 신규 12개 테스트: 시드 재현/다양성, 점수·미래 수량 독립성, 도착 정보 경계, 기존 제약 재검사, 경계/높이/회전/가반하중 거절, 누적하중, 재고 수량, 보류 박스 회수.
- 기존 입고·재고·버퍼·전략·로봇 구성 회귀 62개 통과. 총 74개 고유 테스트. TypeScript와 Vite 프로덕션 빌드 통과.
- 실제 브라우저 Worker에서 기존 `strategyDemo()` 혼합 18개, 팔레트 1000×800×1400 mm, 입고 시드 42, 계획 시드 2026, ONLINE_SEARCH, 이상적 로봇 모드로 비교했습니다. 물리 엔진 검증은 실행하지 않았습니다.
- [실제 CSV](random-placement-seed42.csv): Greedy/MACS/Lookahead 4개, Tetris Reserved 6개, Dynamic Reservation/Future-Aware Hybrid 14개, 무작위 6개. 무작위 높이 330 mm, 계산 중앙값 3.5 ms; Hybrid 631 mm, 90.1 ms. 1회 표본이며 일반적인 성능 우위를 뜻하지 않습니다. 타이밍은 장비·브라우저·부하에 따라 달라집니다.
- 기본 online-task 입력은 모든 비교 방식이 첫 박스에서 기존 제약으로 중단되는 것도 확인했습니다. 무작위 모드를 추가하기 위해 제약을 완화하지 않았습니다.
