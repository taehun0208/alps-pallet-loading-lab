# 단일 로봇 롤러 대기열 (v29)
직선 벨트 끝에 2400 mm 경사 롤러와 말단 정지대를 추가한다. 벨트 450 mm에서 말단 250 mm로 내려간다. 추가 벨트 길이는 합계를 상류에 적용해 로봇과 롤러 정지대가 이동하지 않는다. 다중 로봇 루프는 유지한다.

길이 mm, 시간 s. 정속 160 mm/s. 박스별 수평 외접원 지름으로 간격을 계산하고 최소 100 mm 간격을 유지한다. FIFO 선두만 정지대에서 집기 가능하다. 예약만으로 슬롯을 비우지 않고 파지 뒤 박스 높이+100 mm에 대응하는 상승 시간이 지난 후 후속 박스를 전진시킨다. 가득 차면 벨트와 입고에 역압을 적용한다. 스캔은 시간만으로 판정하지 않고 실제 스캐너 통과 위치에 연동한다. 찌그러짐은 기존 격리 팔레트로 우회한다.

실행 불가 선두는 30초·2회 판단 후 적재 중인 팔레트를 먼저 교체한다. 빈 팔레트에서도 불가능하면 수동 처리 대기로 분리하고 적재 성공으로 계산하지 않는다. 실제 분리 장치의 구동 모델은 없다. 상태와 이유를 이력 JSON으로 확인한다.

정속 이송·기하학적 간격 정지 근사다. 중력, 마찰, 롤러 슬립, 정지 충격, 실제 로봇 IK/흡착은 검증하지 않는다. 박스는 강체·수평 자세를 유지한다고 가정한다. 기존 적재 충돌·하중·지지 검사는 유지한다.

검증: vitest의 pallet-roller-queue, pallet-stream, pallet-intake, pallet-straight-box-view, pallet-stream-return, pallet-reject-pallet, pallet-stream-settings. TypeScript 및 Vite 빌드. 브라우저에서 실제 롤러 대기·정지 집기·적재 및 박스 보존을 확인한다.
