# 로봇별 두 팔레트와 마지막 서브 벨트 합류

연속 공정의 단일·확장 탭은 로봇마다 P1/P2 두 장을 사용합니다. 로봇 4대는 독립 적재 팔레트 8장을 담당합니다. 불량 전용 팔레트는 이 수에 포함하지 않습니다. 기존 실험·벤치마크의 단일 팔레트 알고리즘과 입력은 유지합니다.

## 중앙 판단과 상태

- `Pallet.palletsPerRobot=2`: 연속 대시보드에서 적용. 필드가 없으면 기존 한 팔레트 동작을 유지합니다.
- `palletStations.ts`: 팔레트별 로컬 좌표와 고정 로봇 좌표를 구분합니다. P2는 P1 왼쪽에 가로 규격+300 mm만큼 떨어져 있습니다. 작업셀 간격은 두 팔레트의 폭을 고려합니다.
- P1/P2는 배치 목록·버전·출고 단계·교체 이력을 따로 관리합니다. 후보는 양쪽에서 기존 회전·지지·누적 하중·최대 높이·경로·가반하중 제약을 통과해야 합니다.
- 중앙 계획기는 각 팔레트의 기존 적재 점수, 낮은 배치 높이, 관측된 후속 박스의 공간 손실을 비교합니다. 유효한 후보 가운데 더 좋은 위치를 선택합니다. 전역 최적해 보증은 아닙니다.
- 한 로봇은 팔레트가 둘이어도 동시에 하나의 명령만 수행합니다. 다른 로봇은 경로 예약 충돌이 없으면 함께 동작합니다. 분기 배차와 실제 선두 집기 시점 사이에 상태가 달라지면 팔레트를 다시 선택합니다.
- 다른 팔레트의 적재물도 운반 경로의 장애물로 검사합니다. 실제 로봇 전체 링크·흡착·AMR 충돌 검증 범위는 기존과 같습니다.

## 곡선 끝단

`conveyorTail.ts`는 마지막 로봇의 위치보다 700 mm 앞에서 메인 직선을 끝내고, 반경 700 mm의 90° 곡선 한 번으로 꺾은 뒤 서브 정지대까지 바로 내려오는 경로를 정의합니다. 오른쪽으로 넘어가 되돌아오는 U자 우회는 없습니다. 3D 표면·레일과 박스 이동이 같은 거리 기준 경로를 사용합니다.

마지막 로봇에는 메인 벨트에서 바로 내려오는 별도의 직선 분기를 두지 않습니다. 중앙에서 마지막 로봇으로 배정한 박스와 배차 대기 후 끝단으로 진행한 박스 모두 이 곡선 한 경로로 정지대에 도착합니다. 마지막 서브 벨트는 곡선 끝의 집기 데크만 표시하며, 앞선 로봇들의 직선 분기는 유지합니다.

중앙 배차 대기 상한을 넘긴 정상 박스는 끝에서 떨어지거나 출구 성공으로 기록되지 않습니다. 곡선을 따라 마지막 서브 정지대로 들어가 P1/P2 후보를 재검토합니다. 마지막 서브에 박스가 있으면 곡선에서 간격을 두고 기다립니다. 곡선에서는 호 길이뿐 아니라 실제 중심 간 거리와 박스 외접 반경으로 간격을 검사합니다. 집기 불가능한 박스는 기존 제한된 재검토·팔레트 교체 후 수동 처리 대기로 분리합니다.

불량 박스는 기존 입구 스캐너와 분기 전 푸셔에서 격리되어 이 경로에 들어가지 않습니다. 컨베이어는 자세를 유지하는 운동학적 이송 가정이며 실제 롤러 마찰·회전·접촉력·정지 충격의 검증 결과가 아닙니다.

## 검증

`tests/pallet-dual-pallet.test.ts`에서 4대/8장, 좌표 변환, P1 교체 중 P2 적재, 높이 제한에 따른 다른 팔레트 선택, 4대 동시 명령, 단일 직선 롤러의 두 팔레트 사용, 불규칙 박스와 불량 이벤트의 종료·수량 보존, 곡선 연속성, 마지막 서브 전용 합류와 정체 시 겹침 방지를 검증합니다. 길이 mm, 질량 kg, 시간 s를 사용합니다.
