# 2026-10-10 관측 결과

측정 환경: darwin arm64 / Apple M5 / Node v24.14.1. 공유 개발 컴퓨터에서 측정했으며 전용 장비의 통제된 속도 실험이 아니다. 준비 계산은 제외했다.

조건: 1,200×1,000 mm 팔레트 1개, 6품목×12개, 후보 48개, 보류 2개, 판단 기한 250 ms. 선택용 시드 42·43, 검증용 1042·1043.

180개 중 148개가 기한 내 종료했고, 32개는 기한 초과로 종료했다. 확정 배치의 모델 내 위반은 0건이다. 기한 초과는 미래 탐색 후보에서 발생했고 늦은 배치는 적재하지 않았다.

1200 mm의 선택된 Greedy는 로봇 제약 미적용·적용 배치가 동일했다. 기본 작업공간과 공구에서는 이 후보의 로봇 제약이 활성 제약이 되지 않은 결과다. 로봇 제약이 일반적으로 공짜라는 뜻이 아니다. 화면에서 그리퍼 폭·도달 반경·작업공간 높이를 바꾸어 같은 비교를 다시 실행할 수 있다.

800 mm에서는 Compact가 선택됐고 1200·1600 mm에서는 Greedy가 선택됐다. 높이를 키우면 분모가 커지므로 적재 개수가 늘어도 적재율은 낮아질 수 있다. 1600 mm는 전체 주문 부피가 팔레트 용적보다 작아 공급 부피 상한도 100% 미만이다.

구역 선호는 공간 배치도 바꾸기 때문에 이번에는 적재율이 높아졌다. 다른 부서 인출 차단 수는 항상 감소하지 않았다. 따라서 그 결과만으로 매장 작업시간 단축을 주장하지 않는다.

검증: 신규 엔진 10개 테스트와 ALPS·평가·로봇 관련 회귀를 포함해 6개 파일 72개 통과. 400×400×400 mm에 200 mm 정육면체 8개를 채우는 알려진 정답에서 100% 적재를 확인했다. 이 소형 사례의 최적성은 일반 혼합 상품에 이전하지 않는다. 브라우저에서 작은 입력의 Worker 계산, 선택·검증 표시, 3D 단계 재생을 확인했다. JSON 다운로드 완료 확인은 사용자 중단으로 수행하지 못했다.

실제 로봇 IK·전체 링크 충돌·흡착·동적 물리는 검증하지 않았다. 모델 가정과 지표 해석은 [README](README.md)를 참고한다.
