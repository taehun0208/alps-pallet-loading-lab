# 이상적 팔레타이징: 알고리즘 정의와 선행 실험

2026-10-03. 웹의 랜덤 생성/프레임 UI를 수정하기 전에 `baseline → candidate-v1 → surface-v2 → portfolio-v3 → final → 새 holdout` 순서로 순수 TypeScript 엔진을 실행했습니다. 모델의 변경과 측정 자료는 각각 JSON에 남아 있습니다. 그리퍼 폭과 실제 로봇은 이번 기본 문제의 범위에서 제외했습니다.

## 문제와 가정

단일 팔레트, 직육면체, x/y 바닥·z 높이, 최소 모서리 mm, 질량 kg입니다. 각 박스 내부 질량은 균일해 자체 무게중심이 기하 중심입니다. 종류별 무게는 서로 달라도 됩니다. 기본 방향은 상하 고정, 바닥 0/90°. 팔레트 돌출은 **0 mm**, 관통은 금지, 맞닿음은 허용합니다.

박스 하나가 도착하면 이미 확정한 좌표를 바꾸거나 정상 박스를 건너뛰지 않습니다. 임시 버퍼도 없습니다. 전체 종류/수량은 알려져 있지만 실제 다음 종류는 공개하지 않습니다. `ArrivalEnvironment`만 순서를 소유하고 계획기에 현재 관측·남은 수량·확정 적재만 투영합니다. 입력 생성용 세트 시드, 입고 시드, 가상 탐색 시드는 독립입니다. 반복 비교는 동일한 박스 세트와 입고 순서를 모든 정책에 제공합니다.

`robotMode: ideal`은 그리퍼 크기·질량·가반·작업공간·로봇 경로 검사를 실행하지 않습니다. 1초 표시 경로는 시각 재생용이며 작업시간/이동거리로 누적하거나 점수에 쓰지 않습니다. 기존 `gripper` 모드는 명시적으로 선택하는 별도 근사입니다. 관절·토크·전체 링크 충돌은 두 모드 모두 미검증입니다.

## 후보 생성과 제약

팔레트 경계와 기존 박스의 양쪽 모서리에서 footprint를 맞추는 x/y를 만듭니다. 서로 다른 박스에서 생긴 x/y 경계도 교차 조합합니다. 각 footprint의 착지 높이는 아래와 겹치는 박스의 최고 상단으로 정해 지붕 아래로 순간 이동하지 않습니다. 이는 [Crainic–Perboli–Tadei의 모서리/극점 후보 개념](https://iris.polito.it/handle/11583/1512183)을 참고한 프로젝트의 상부 투입 변형이며 논문 알고리즘의 재현은 아닙니다.

경계·높이·관통·최소 지지율·자체 중심 투영은 먼저 값싼 기하 검사로 거릅니다. 상세 후보 예산은 그 이후 적용하고 높이·방향·바닥 사분면별로 후보를 나눠 보존합니다. 기본 상세 후보 128개, 가상 후속 후보 24개입니다. 모든 정책이 같은 현재 후보와 하드 제약을 공유합니다. 희소 후보 및 상한이 있으므로 막힘은 **검토한 후보에서의 실패**이며 전체 연속 공간의 불가능성 증명이 아닙니다.

기본 지지율 95%, 독립 기둥 높이/받침의 짧은 폭 상한 2.0, 접촉 여유 10%, 횡가속도 가정 0.15 g, 하중 여유 계수 1.25를 사용합니다. 지지로 연결되지 않은 옆면을 결속 구조로 가정하지 않습니다. 재질 강도/마찰은 이전 실험의 예제 또는 실제 입력값을 유지합니다. 미지정 강도는 미검증입니다.

## 균일 질량과 정적 반력

각 박스는 자기 질량을 중심에 작용시킵니다. 위쪽에서부터 접촉 반력을 전달하며 각 수평 접촉면에서 다음을 만족하는 **압축 방향의 비음수 수직 반력**을 찾습니다.

```text
Σ N_i = 아래로 전달되는 총 질량 (kgf에 비례; g는 공통이라 소거)
Σ N_i x_i = 총 x 모멘트
Σ N_i y_i = 총 y 모멘트
```

접촉 사각형의 네 모서리를 반력 표본점으로 사용합니다. 면적 비례 균등 압력을 기준으로 3×3 선형계를 풀어 반력을 보정하고, 음수 반력의 활성점을 제외해 다시 풉니다. 특이해지면 지지 다각형 내 삼각형의 비음수 무게로 가능한 평형을 구합니다. 각 부모에 `share`(반력 비중), `forcePoint`(반력 작용점), `area`(실제 접촉 면적)를 저장합니다. 상부 하중이 추가되면 **모든 아래쪽 반력을 다시 계산**하며 기존 좌표는 그대로 유지합니다.

종전의 단순 면적 분담은 넓은 상자의 무게중심을 모든 받침에 그대로 전달해 잘 지지된 다중 받침도 탈락시킬 수 있었습니다. 이번 모델은 전달된 힘의 작용점으로 수평 모멘트를 보존합니다. 각 하부 허용 상부 하중과 작용점의 지지 다각형 여유를 검사합니다. 높이 방향 질량과 횡가속도 여유는 반력 비중에 따른 보수적 근사입니다.

반력은 정적으로 불확정할 수 있으므로 선택한 분담이 실제 압력 분포의 유일한 답은 아닙니다. 압축 변형·재질 강성·흡착·운송 진동은 계산하지 않습니다. 힘/모멘트 평형 개념은 [정적 평형을 고려한 적재 연구](https://www.sciencedirect.com/science/article/pii/S0191261515302022)의 공개 초록을 참고했고, 여기의 반력 계산기는 프로젝트 자체의 수직 접촉 근사입니다.

## 세 정책

1. **기본 배치:** 남은 물량 중 표면 공간 표본이 있는 비중이 최대인 후보를 남기고, 공간 기회가 최고값과 0.02 이내인 후보에서 상단 높이 → y → x → 방향 순으로 선택합니다.
2. **Greedy:** 높이·요철·근사 빈 공간·평탄면·하중 균형·기둥·상부 하중 사용·잔량 기회·강한 받침 보존/활용을 평가합니다. 같은 높이로 이웃/벽과 맞닿는 둘레 비율을 보상하고, 더 큰 남은 종류가 필요로 하는 받침을 작은 박스로 끊는 경우 비용을 줍니다.
3. **다중 정책 Rollout:** 점수 상위 후보 외에 기본 배치 후보와 높이/방향/지지 부모가 다른 후보를 K=6 안에 보존합니다. 같은 가상 순서 4개·깊이 3을 모든 후보에 적용합니다. 각 순서에서 Greedy와 기본 배치 후속 정책을 독립 실행합니다. 각 가상 순서의 더 좋은 후속 결과를 사용해 막힌 표본 비중 최소 → 평균 추가 적재 최대 → 합산 점수 순으로 고릅니다.

다중 후속 정책의 좋은 결과를 사용하는 값은 낙관적 근사이며 실제 입고 순서를 안다는 뜻이 아닙니다. 실제 후속 단계에서 동일한 결과를 보장하지 않습니다. 가상 순서는 남은 수량의 비복원 표본이며 실제 큐/입고 난수는 전달하지 않습니다. 어떤 정책도 학습 모델, LLM, 외부 API를 호출하지 않습니다.

```text
S = −30 Hmax/Hlimit −16 Hmean/Hlimit −20 roughness/Hlimit
    −25 blockedVolume/allowedVolume +8 flatRatio −12 loadImbalance
    −24 slenderness/configuredLimit +32 remainingOpportunity
    −24 foundationPenalty −12 peakLoadUtilization
    +12 equalTopContactRatio −24 lostLargeSurfaceDemandRatio
F = .55 meanAdded/depth + .20 meanAddedVolume/maxSampleVolume
    + .15 (1 − meanFinalHeight/Hlimit) − .35 blockedSampleRatio
combinedScore = S + 45 F
```

이상적 모드의 로봇 시간 항은 0입니다. 잔량 기회는 12×10 표면 표본을 사용하고 남은 수량×체적으로 가중합니다. 넓은 받침 손실은 남은 큰 박스가 원래 부모 면에 들어가는지, 현재 박스가 나눈 네 사각형에 들어가는지 비교합니다. 두 항 모두 근사이며 실제 배치에서는 전체 기하·정적 평형·허용 하중을 다시 검사합니다.

## 랜덤 입력과 선행 실험

기본 랜덤 세트는 5종/30개, 치수 단위 50 mm, 예제 밀도 120 kg/m³입니다. 가로 200~600, 깊이 200~500, 높이 150~350 mm이며 종류마다 최소 하나를 만들고 나머지 수량을 무작위 배분합니다. 질량은 0.01 kg 단위로 반올림합니다. 각 박스 내부 질량은 균일합니다. 입고 시드를 바꿔도 치수와 수량은 바뀌지 않습니다. 임의 랜덤 세트가 한 팔레트와 설정한 안정성 제약 아래 전부 들어간다는 보장은 없습니다.

최종 개발 입력은 reference/identical/mixed/materials/large-late/impossible 및 세트 시드 101/107/113으로, 세 정책 총 27회입니다. 정적 평형 모델을 수정한 후 새 세트 시드 9001/9011/9029/9041/9067/9091로 세 정책 총 18회를 검증했습니다. 최종 배치마다 경계·관통·높이·지지·정적 평형·상부 하중과 로봇 시간 미평가를 확인했습니다.

## 다음 확장점

기존 gripper 근사 모드를 별도로 선택할 수 있습니다. 이후 로봇 베이스 위치·관절 가동 범위·토크·전체 링크 충돌, 포장재 압축 자료, 운송 가속도를 각각 추가할 수 있습니다. 이 입력이 없는 현재 결과를 실제 산업용 로봇 실행 가능으로 표시하지 않습니다. 카카오톡에서 언급한 현실 제약은 이 명확한 확장점으로 유지하고, 이번 기본 알고리즘에서는 요청에 따라 그리퍼 폭을 제외합니다.
