# 서로 다른 혼합 박스 · 입력과 알고리즘 수정

2026-10-04. 생성 모델 변경과 순수 엔진 실행을 먼저 진행하고 이후 웹을 연결했습니다.

## 이전 모델의 문제

기본 기준 입력은 4개 규격에 높이 200 mm, 랜덤 입력은 50 mm 단위 치수·5개 규격 반복·고정 밀도를 사용했습니다. 재질 강도도 재질별 고정 예제에 의존했습니다. 기하 엔진이 임의 치수를 지원해도 이런 생성 방식과 같은 높이 보상은 실제 다양한 입고를 설명하기 어렵습니다.

## 새로운 입력

기본은 각 수량 1인 서로 다른 치수 30개입니다. 기본 세트/입고 시드는 20261004/42입니다.

| 축 | 생성 범위 |
|---|---|
| 가로 | 150~760 mm |
| 깊이 | 120~560 mm |
| 높이 | 90~460 mm |

각 축은 범위 안의 정수 mm를 독립 균일 추첨합니다. 동일한 치수 튜플만 중복 제거하며 팔레트에 들어가는지, 안정한지, 잘 맞물리는지로 선별하지 않습니다. 좁은 범위에서 서로 다른 치수를 충분히 만들 수 없으면 입력 오류를 반환합니다. 반복 규격은 별도 선택입니다.

얇은/강화 골판지, 얇은 플라스틱/플라스틱 토트, 목재 포장 프로필을 추첨합니다. 내용물 밀도 35~320 kg/m³와 포장 자체 무게를 별도로 생성해 모든 박스에 같은 밀도를 부여하지 않습니다. 각 박스 내부 질량은 균일한 것으로 계산합니다. 프로필의 상부 하중/마찰/포장 무게 범위는 다음과 같습니다.

| 프로필 | 상부 하중 예제 kg | 마찰 예제 | 포장 무게 예제 kg |
|---|---:|---:|---:|
| 얇은 골판지 | 8~28 | .28~.55 | .08~.5 |
| 강화 골판지 | 24~65 | .30~.60 | .15~.8 |
| 얇은 플라스틱 | 12~45 | .20~.50 | .3~1.5 |
| 플라스틱 토트 | 38~110 | .25~.65 | .8~3 |
| 목재 포장 | 40~150 | .35~.70 | 1~4 |

범위가 겹쳐 플라스틱이 종이보다 반드시 강하지 않습니다. 강도 보정 .55~1, 위 적재 금지 확률 8%도 별도로 추첨합니다. 위 적재 금지는 상부 허용 0입니다. **이 분포와 허용량은 실측 자료나 재질별 보증값이 아닌 합성 예제입니다.** 생성값은 `maxLoadSource: synthetic`으로 기록하고 화면에서도 생성 예제값으로 표시합니다. 사용자가 하중을 편집하면 입력값으로 구분합니다. 현장 자료를 JSON이나 박스 편집으로 입력할 수 있습니다.

세트 시드와 실제 입고 시드는 독립입니다. 남은 수량에서 비복원 추첨하고 전체 재고는 알고리즘에 공개하지만 실제 미래 입고/입고 시드는 전달하지 않습니다. 팔레트·제약은 웹에서 새 세트를 만들 때 유지합니다. 이전 gridMm 메타데이터와 입력도 호환되며 새 UI 생성은 개별 치수 모델을 사용합니다.

## 알고리즘 보완과 시험 과정

1. 개별 치수/무게/강도 모델과 측면 평가를 적용한 첫 버전으로 24개씩 3세트×3정책을 실행했습니다. 결과는 [첫 실행 JSON](pallet-field-first-pass.json)입니다. 첫 세트는 9/9/10개, 두 번째 0/0/0개, 세 번째 6/6/6개였습니다.
2. 접촉 평가에서는 같은 상단 높이를 요구하던 접촉 보상을 **실제 측면 겹침 면적 / 전체 측면 면적**으로 변경했습니다. 높이가 다른 137/293 mm 박스의 접촉 면적을 별도 검사했습니다. 이 면적은 조밀성 점수에만 사용합니다.
3. 잔량 평가가 100 mm 표면 격자 때문에 실제 받침을 놓치는 사례를 재현했습니다. 322×231 mm 받침 위의 301×207 mm 박스는 격자 방식에서 0, 실제 좌표 방식에서 1의 공간 적합 비중을 보였습니다. 기본 잔량 검사는 실제 박스/팔레트 경계 후보를 방향별 최대 32곳 표본으로 검사하도록 바꿨습니다.
4. 새 기본 30개 입력과 나머지 24개 입력으로 세 정책을 재실행했습니다. 아래는 이 최종 엔진 실행 결과입니다. 첫 세트 수량이 24→30으로 달라졌으므로 첫 실행과 성능 향상 비율로 직접 비교하지 않습니다.

잔량 표본은 겹침/높이/지지/직계 부모의 하중 여유 검사입니다. 반력·전체 하부 하중·기둥 검사는 실제 후보 배치에서 다시 적용합니다. 표본 적합은 미래 성공의 보장이 아닙니다. 높이 요철·빈 공간·바닥 여유에는 12×10 표면 근사를 계속 사용합니다.

모든 프레임에서 물량 보존과 공통 관측 순서를 검사하고, 확정 배치의 경계/관통/높이/95% 지지/정적 평형/하중 사용≤100%를 확인했습니다. 3개의 재고 세트는 대표성 있는 산업 성능 벤치마크를 뜻하지 않습니다. Rollout은 이 실험에서 더 느리고 적재량도 항상 높지 않아 웹 기본을 Greedy로 설정했습니다.
