# 8개 작업 구역의 순환 적재

8개 독립 팔레트와 팔을 원형으로 배치하고 R1 → R2 → … → R8 → R1로 전달한다. 각 팔은 독립 시계를 쓰며 동일 전달대와 겹치는 운반 경로만 예약한다. 전달대에 내려놓은 뒤 받는 팔이 직접 적재 또는 자기 재고 보관을 결정한다.

## 높이 채우기 정책

1. 도착한 유한 재고를 시드로 섞어 8개 구역에 한 번씩만 분배한다. 미도착 박스는 사용하지 않는다.
2. 각 박스의 허용 자세와 빈자리 후보를 생성하고 경계, 겹침, 지지, 누적 하중, 정적 평형, 세워진 박스의 돌출 높이를 검사한다.
3. 낮은 빈자리와 넓은 지지면을 먼저 채운다. 남은 박스를 중복 사용하지 않는 높이 조합으로 상단의 예상 잔여 높이를 비교한다. 이 조합은 순위용 추정치이며 후속 실제 배치는 매번 다시 검사한다.
4. 상부 적재 금지 박스는 일반 박스 뒤로 보류한다. 다른 구역에 남은 일반 박스도 현재 받침에 놓일 수 있다면 받침을 덮지 않는다.
5. 자기 팔레트에 놓을 수 없는 박스는 다른 구역의 후보를 확인하고 옆 전달대로 순환시킨다. 모든 구역의 검토 후보에서 놓이지 않는 박스는 재고에 보존한다.
6. 한 번 전달한 방향은 적재 수량이 증가한 경우에만 다시 시도한다. 적재 변화 없는 무한 순환을 방지하면서 새 지지면에는 재도전한다.
7. 최대 높이의 95%는 표시용 지표다. 도달 후에도 배치 가능한 동안 계속 채우며 높이 상한을 초과하지 않는다. 종료는 재고 소진 또는 검토 후보 없음으로 구분한다.

## 입력과 검증 범위

높이 실험은 기본 1,000 × 800 × 1,600mm 팔레트, 불규칙 치수의 일반 16종 192개를 사용한다. 치수는 시드로 생성하며 배치 좌표는 미리 저장하지 않는다. 허용 하중은 명시한 합성 값이며 무게는 박스 전체에 균등하게 분포한다고 가정한다. 기존 입력은 ‘현재 박스 세트 사용’으로 별도 실행할 수 있다.

일반 박스는 허용된 최대 6자세를 비교한다. 종별 24개 후보 사전 검사, 상위 3종 64개 확대 검사, 후보가 없을 때 전체 96개 재검사를 사용한다. 전 구역 적재 가능성 역시 유한 후보 검사다. 전역 최적해나 임의 재고에서의 최대 높이 도달을 보장하지 않는다.

대각선 구역의 장애물 검사는 장애물 구역 좌표로 옮긴 운반 선분과 확장 박스로 계산한다. 팔은 가상 모델이며 전체 링크의 연속 충돌, 흡착, 포장 변형, 실물 로봇 운용은 검증 범위 밖이다. 높이 실험의 기본 적재 환경은 이상적인 적재 모델이다.

## 검증

- `tests/pallet-relay.test.ts`: 8대 동시 시작, 독립 완료, 인접 수신/보관, R8→R1, 중복 확정 방지, 재고 보존, 진전 없는 순환 종료, 대각선 경계.
- `tests/pallet-eight-height.test.ts`: 전체 실험 실행 후 각 팔레트의 모든 배치를 순서대로 하드 제약 재검사.
- `docs/pallet-eight-height.json`: 실행 입력, 최종 배치, 각 높이와 용적 이용률, 전달 수량, 중단 사유를 저장한 측정 결과.
- 화면의 실행 JSON에는 8개 구역과 전달대 상태, 독립 실행 시간, 모든 완료 이력과 높이 요약이 포함된다.
