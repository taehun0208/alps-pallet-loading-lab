# Mixed Palletizing · 온라인 알고리즘 재설계

2026-10-04~05. 사용자 첨부 요구사항 두 장과 최초 상세 사양을 다시 대조하고, 알고리즘을 먼저 실행·보완한 뒤 웹에 연결했습니다. AI·학습 모델·외부 추론 API를 사용하지 않습니다.

## 이전 구현에서 어긋난 부분

이전 기본값은 모든 박스를 꺼낼 수 있는 **전체 재고 선택**이었습니다. 큰 박스를 먼저 고르는 이 방식은 실제 투입 순서를 사전에 알 수 없는 온라인 적재와 조건이 다릅니다. 또한 자체 중량 순서 규칙과 로봇 검사가 꺼져 있었고, 잔량 공간 검사에서는 누적 하중과 로봇 접근이 빠져 있었습니다. 가상 순서 전체를 본 뒤 좋은 후속 정책의 결과를 고르는 기존 Portfolio도 과제 기본에서 제외했습니다.

현재 기본은 `online-task` / `arrival` / `online` / Greedy입니다. 전체 재고 재정렬, 무게 분담 규칙, 이상적 환경, 이전 알고리즘은 이름에 연구 조건을 표시해 보존합니다. 이들의 과거 결과를 현재 과제의 성능으로 비교하지 않습니다.

## 한 단계의 알고리즘

1. 환경이 현재 박스 하나를 관측합니다. `PlanningInput`에는 실제 미래 순서나 입고 난수 상태가 없습니다. `planOnline()`은 전체 선택 재고를 넘기면 거절합니다.
2. 팔레트/박스 모서리의 교차 정렬, 받침 중앙, 기존 하중의 치우침을 상쇄하는 위치, 팔레트 중앙을 생성합니다. 위에서 내렸을 때 처음 접촉하는 높이가 착지 높이입니다. 닫힌 공간으로 순간 이동하지 않습니다.
3. 기본 최대 96개 후보에 기하·정적 반력·재질 하중·자체 중량 순서·로봇 근사 하드 검사를 적용합니다. 면적 지지율 95%, 접촉 허용오차 0.5 mm, 돌출 0 mm입니다. 높은 점수로 하드 실패를 덮을 수 없습니다.
4. Greedy/Rollout은 점수 상위, 낮은 기준 위치, 높이/방향/지지부/사분면별 다양성으로 최대 6개 상세 후보를 고릅니다. 상세 후보 밖의 유효 위치는 화면에 **현재 배치 검사만 완료**라고 표시합니다.
5. 잔량 종류별로 방향·층·사분면·균형 위치를 포함한 최대 8개 후속 위치를 검사합니다. 현재 배치 전과 후 모두 전체 하드 검사를 사용합니다. 따라서 상부의 직접 받침뿐 아니라 모든 조상의 강도·반력·무게중심과 로봇 경로도 검사합니다.
6. 선택한 현재 박스를 다시 검사한 뒤 확정합니다. 수량 하나만 소비하며 모든 반력/하부 하중을 갱신합니다. 정상 박스의 검토 위치가 없으면 그 ID와 잔량을 보존해 중단합니다. 손상·누락 외에 정상 박스를 몰래 제외하지 않습니다.

후속 종류 t의 수량을 n(t), 부피를 V(t), 검사 위치 수를 P(t), 유효 위치 수를 F(t)로 둡니다.

`위치 기회 O = Σ[n(t)V(t) × F(t)/P(t)] / Σ[n(t)V(t)]`

`표본을 잃는 물량 L = Σ[n(t)V(t) × I(배치 전 F(t)>0 이고 배치 후 F(t)=0)] / Σ[n(t)V(t)]`

P=0이면 해당 종류의 위치 기회는 0입니다. 잔량이 없으면 O=1, L=0입니다. 수량×부피로 가중하며, 확률이나 동시에 적재할 수 있는 수량으로 해석하지 않습니다. `잔량 기여 = 32 × (O_after − O_before − 2L)`가 기본 점수에 추가됩니다.

## 세 정책의 차이

| 정책 | 현재 박스 선택 기준 | 잔량/가상 순서 |
| --- | --- | --- |
| BL | 유효 후보의 낮은 상단 높이 → y → x → 방향 | 선택 결과의 잔량 검사를 진단으로 기록. 단순 기준 정책 |
| Greedy · 기본 | 상세 후보 중 L 최소 → 합산 품질 점수 → BL 동률 해소 | 잔량 모든 종류의 실제 제약 위치 표본을 사용 |
| Rollout | L 최소 → 가상 막힘 비율 최소 → 평균 추가 적재 수 최대 → 점수 | 잔량 수량에서 비복원 추출한 같은 4개 가상 순서 × 최대 3단계 |

Rollout의 계획기 시드는 입고 시드와 별개입니다. 모든 현재 후보에 같은 가상 순서를 적용합니다. 후속 단계는 각 단계의 현재 가상 관측만 쓰는 **고정 빠른 Greedy**입니다. 상세 잔량 재검사를 매 가상 단계에 반복하지 않고 기하/정적/로봇 하드 검사와 품질 점수로 선택합니다. 미래 전체를 본 후 좋은 후속 정책을 고르지 않습니다. 매 가상 확정 뒤에도 반력과 누적 하중을 갱신합니다.

가상 결과의 점수 기여는 기본 가중치 45에서 다음과 같습니다.

`45 × (0.55 × 평균 추가 수 / 탐색 깊이 + 0.20 × 평균 추가 부피 / 표본 최대 부피 + 0.15 × (1 − 평균 최종 높이 / 높이 제한) − 0.35 × 막힘 비율)`

이는 프로젝트의 제한된 탐색 휴리스틱입니다. 전체 최적해, 실제 다음 박스의 예측, 모든 정책보다 좋은 성능을 주장하지 않습니다.

## 아랫단 중심과 재질

박스 내부 질량은 균일합니다. 자체 기하 중심의 중량과 위에서 전달된 반력을 합쳐 각 접촉면의 합력 중심을 계산합니다. 여러 받침에 걸친 상자의 하중은 반력 비율과 작용점으로 나눠 전달합니다. 같은 상부 전체 무게를 모든 받침에 중복 배정하지 않습니다.

`합력 중심 x = (자체 중량 × 자체 중심 x + Σ[상부 반력 × 작용점 x]) / 누적 중량`

y도 같습니다. 각 하부 접촉에서 힘·x/y 모멘트 보존과 압축 반력 ≥0을 검사합니다. 합력 중심과 접촉 다각형 경계의 최단 거리에서 필요 여유를 뺀 값이 전도 여유입니다. 필요 여유는 기본 `max(짧은 지지 폭 × 0.1, 전달 높이 근사 × 0.15)`입니다. 전달 질량의 높이는 반력 비율로 나눈 근사이며, 횡가속도 0.15g 역시 설계 가정입니다.

아랫단 치우침 점수는 하중 받는 접촉의 최악 정규화 편차 75% + 누적 중량 가중 평균 25%입니다. 기본 `−2 × (균형 12 + 안정성 24) × 치우침`을 추가합니다. 측면 접촉은 조밀성 점수이고, 끈/랩이나 구조 결속으로 취급하지 않습니다.

재질의 허용 상부 하중은 `입력/예제 허용값 × 강도 보정 / 여유 계수 1.25`입니다. 합성 강도와 사용자 입력 출처를 표시합니다. 실제 종이 압축·크리프·내용물 편중·흡착력은 계산하지 않습니다. **중량 순서 조건과 압축 내구성 조건을 둘 다 통과해야 합니다.**

## 먼저 실행하고 보완한 과정

첫 실행은 기존 높이/짧은 받침 폭 2.0을 하드 제한으로 유지했습니다. seed 7919의 첫 박스 `177×211×417 mm`가 이 규칙만으로 거절되어 세 정책 모두 0/24였습니다. 실제 접촉면 합력과 횡가속도 여유는 통과했습니다.

이 추가 비율 규칙은 첨부의 필수 조건이 아니므로 과제 기본에서는 **점수 지표**로 변경했습니다. 접촉면 합력·반력·전도 여유·강도·무게 순서의 하드 검사는 유지합니다. `100×100×2000 mm`처럼 필요 여유를 확보하지 못하는 상자는 여전히 거절되는 시험도 포함했습니다. 연구 설정에서 비율 하드 제한을 다시 켤 수 있습니다.

가상 확정마다 기존 받침의 반력 분담도 갱신하도록 보완했습니다. [첫 실행](pallet-online-first-pass.json), [접촉 여유 기준 보완 실행](pallet-online-contact-pass.json), [최종 실행](pallet-online-before-requirements.json)을 각각 보존합니다.

이 표는 **적재 수의 일반적 개선을 입증하지 않습니다.** 개선의 확인 대상은 미래 정보 분리, 필수 규칙 적용, 잔량 위치의 전체 제약 검사, 인과적 가상 탐색입니다. 완성되지 않은 실행과 탈락 사유도 데이터에 남겼습니다.

## 기능을 검증한 입력

- `600×400×100` 팔레트에서 현재 `100×400×100 / 2kg`, 미입고 `300×400×100 / 10kg`: 중앙 x=250은 후속 유효 위치를 없앱니다. Greedy/Rollout이 이를 검출해 가장자리를 선택하며 실제 순서대로 2/2개를 배치했습니다. BL도 기준 가장자리로 2/2개입니다.
- 바닥을 전부 덮는 2kg 상자 다음 10kg 상자: 허용 압축 하중이 충분해도 무게 규칙으로 중단합니다. 미입고 상자를 먼저 꺼내거나 현재 정상 상자를 격리하지 않습니다.
- 직접 받침은 강하지만 아래 조상 상자가 약한 입력: 잔량 위치 검사에서 조상 허용 하중 초과를 검출합니다.
- 기하적으로 놓을 수 있지만 높은 옆 상자에 그리퍼가 걸리는 입력: 경로 검사로 거절합니다. 33kg 상자 + 3kg 공구 > 예제 가반 35kg도 거절합니다.
- 신규 편심 하중이 기존 공유 접촉의 분담을 바꾸는 입력: 기존 접촉의 무게 규칙을 다시 검사합니다.
- 실제 입고 시드는 다르지만 공개 현재/수량이 같은 입력: 현재 결정과 가상 순서가 같습니다. 가상 순서는 수량을 초과해 추출하지 않습니다.
- 관측 규격 수정 `180×147×131`, 손상, 누락: 수정 치수를 사용하며 적재/격리/누락/잔량 수량을 보존합니다. 강체 복제 검사와 프레임 재생은 확정 좌표를 바꾸지 않습니다.

검증 명령과 최종 결과는 [VERIFICATION.md](../VERIFICATION.md), 설정·진입 방법은 [PALLET-TETRIS.md](../PALLET-TETRIS.md)에 있습니다.

## 로봇 가정과 다음 연결 지점

현재 과제 예제는 그리퍼 `180×160×160 mm`, 자체 3kg, 가반 35kg, 여유 5mm, 상승 200mm, 속도 650mm/s, 집기/놓기 각각 1초입니다. 작업공간은 x `−1400~1600`, y `−500~1500`, z `0~2600 mm`입니다. 특정 실물 로봇의 검증된 사양이 아닌 편집 가능한 예제값입니다.

상자·그리퍼 스윕과 직육면체 작업공간을 통과해도 실제 관절 자세가 존재한다는 보장은 없습니다. `RobotValidator` 확장점은 있지만 현재 계획기에 실제 모델은 연결되어 있지 않습니다. 관절/IK/전체 링크 충돌·토크, 포장 압축 시험값, 흡착 방향별 파지 가능성은 별도 입력과 검증이 필요합니다. Rapier는 강체 마찰/낙하 실험이며 이 검사를 대신하지 않습니다.

현재 후보·잔량·Rollout은 모두 제한된 희소 탐색입니다. “검토 위치에서 없음”은 연속 공간의 불가능성 증명이 아닙니다. 대기 버퍼가 없는 온라인 조건에서는 미래 큰 박스를 아래에 놓겠다는 목적으로 실제 미입고 상자를 먼저 선택할 수 없습니다. 남은 상자에 쓸 지지 공간을 보존하는 것이 가능한 대응입니다.
