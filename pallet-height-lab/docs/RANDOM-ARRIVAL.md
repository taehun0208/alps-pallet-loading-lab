# 재고·다음 입고 모두 무작위 · 2026-10-04

시작 재고의 종류·치수·수량을 무작위로 만들고, 다음 배치할 박스는 매 단계 남은 재고에서 추첨하는 모드를 추가했습니다. 유한 재고이므로 도착할 때마다 한 개를 차감합니다. 재고를 매번 새로 채우거나 배치하기 어려운 박스를 다시 뽑지 않습니다. 기존 고정 재고/섞은 순서 모드도 유지합니다.

## 실행

1. [시뮬레이터](http://127.0.0.1:5173/#pallet)의 **랜덤 박스 세트 · 순서**를 펼칩니다.
2. **재고·입고 모두 랜덤**을 누릅니다. 설정한 종류 수·총 수량으로 새 박스 세트와 입고 시드를 생성하고 매 단계 추첨 모드를 적용합니다.
3. **자동 적재** 또는 **한 단계**로 실행합니다. 확정 배치, 현재 박스, 남은 종류별 수량과 다음 추첨 확률을 관찰합니다.
4. 같은 실험은 **세트 생성 시드**, **무작위 입고 시드**, **입고 추첨 방식: 남은 재고에서 매 단계 추첨**을 지정하고 **이 시드로 세트 생성**을 누르면 재현됩니다. 초기화도 같은 시드의 같은 순서를 재현합니다.
5. **입고 순서만 랜덤**은 기존 박스 구성에 새 입고 시드와 선택한 방식을 적용합니다. 입력 변경은 새 실행이며 기존 확정 기록은 보관됩니다.

## 추첨과 정보 경계

현재 박스 도착 후 종류별 잔량을 qᵢ라고 하면 다음 종류 확률은 qᵢ/Σq입니다. 구현은 남은 개별 박스 배열에서 균등하게 하나를 골라 제거하는 비복원 추첨입니다. 고갈된 종류는 더 이상 도착하지 않습니다. 전체 수량이 0이면 종료합니다.

환경만 입고 시드·난수 상태·아직 도착하지 않은 박스 풀을 소유합니다. 요청한 현재 관측까지 추첨하여 저장하고, 반복 조회·일시정지·후보 선택·이력 재생으로 다시 뽑지 않습니다. 정상 박스 배치가 실패하면 동일 박스를 남긴 채 중단합니다. 다음 박스는 처리하지 않습니다.

계획기는 현재 박스·확정 좌표·남은 종류/수량만 받습니다. 실제 입고 시드나 미래 큐를 전달하지 않습니다. Rollout의 가상 순서는 기존처럼 별도 계획기 시드로 잔량에서 표본화합니다. 같은 입력을 세 정책에 줄 때 실제 입고의 공통 구간은 동일합니다. 미래를 모르는 관점에서 매 단계 추첨과 사전 순서 섞기는 같은 비복원 표본 분포이며, 새 모드는 관측이 필요할 때 실제 추첨하는 실행 방식과 화면의 확률 표시를 제공합니다.

`남은 재고 + 현재 박스 + 확정 적재 + 손상 격리 + 누락 = 시작 물량`을 유지합니다. 현재 박스가 이미 공개됐으므로 화면의 잔량과 확률에는 현재 박스를 포함하지 않습니다. 유효 후보 실패 기록은 물량 소비로 세지 않습니다. 재질·반력·지지·돌출·균일 질량 가정과 그리퍼 폭 제외는 이전 모델을 그대로 사용합니다.

## 실제 입력 실험

새 세트 시드 3개 × 세 정책, 총 9회 실행했습니다. 각 세트는 5종/18개이며 기본 탐색 설정을 사용했습니다. 경계·관통·지지율·높이·정적 평형·허용 하중과 모든 프레임의 수량 보존을 검사했습니다.

| 세트 / 입고 시드 | 정책 | 적재 | 높이 |
|---|---|---:|---:|
| 20261004 / 733 | bl | 18/18 | 750 mm |
| 20261004 / 733 | greedy | 18/18 | 750 mm |
| 20261004 / 733 | rollout | 18/18 | 750 mm |
| 20261005 / 734 | bl | 12/18 | 600 mm |
| 20261005 / 734 | greedy | 16/18 | 800 mm |
| 20261005 / 734 | rollout | 12/18 | 800 mm |
| 20261006 / 735 | bl | 18/18 | 950 mm |
| 20261006 / 735 | greedy | 10/18 | 550 mm |
| 20261006 / 735 | rollout | 10/18 | 550 mm |

세 번째 입력에서 기본 배치가 Greedy/Rollout보다 많이 적재했고, 두 번째 입력에서는 Greedy가 더 많이 적재했습니다. 무작위 세트의 전체 적재나 한 정책의 일관된 우위를 보장하지 않습니다. 개별 박스·관측 순서·잔량·배치·측정값은 [측정 JSON](pallet-random-arrival-measurements.json)에 저장했습니다.

단위 검사는 필요한 시점만 추첨하기, 반복 관측 불변, 동일 시드 재현, 고갈·수량 0 처리, 수량 비례 추첨, 손상/누락/규격 변경, 세 정책의 동일 순서, 중단 시 재추첨 금지, 입력 JSON 호환을 확인합니다. 실행 중 다른 랜덤 세트로 바꿀 때 이전 프레임으로 새 환경의 미래를 먼저 추첨하지 않도록 초기화 대기 상태도 분리했습니다.
