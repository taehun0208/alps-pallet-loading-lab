# HRPal 공식 자료 조사와 공정한 비교 방법

조사일: 2026-10-10 KST. 제품 소유자의 홈페이지·배포 페이지·사용설명서·공식 GitHub만 기술 근거로 사용했다. 프로그램 내부 구현을 재현하거나 HRPal 명의의 성능 수치를 생성하지 않았다.

**결론: HRPal은 실제 HD현대로보틱스의 Windows용 팔레타이징 패턴·로봇 작업 프로그램 생성 소프트웨어다. 실제 프로그램의 출력으로 비교할 수 있지만, 이번에 확인한 공개 자료만으로 내부 적재 알고리즘을 코드로 구현해 같은 알고리즘이라고 부를 수는 없다. 공개 온라인 계획 API와 혼합 상품·무작위 입고 벤치마크도 찾지 못했다. 현재 상태는 “제품 조사 완료, 실제 HRPal 성능 미측정”이다.**

## 1. 제품명과 확인된 기능

공식 홈페이지 표기는 **HRPal**, 기존 배포·설명서는 `HRpal`이다. 조사 시 공식 제품 페이지에는 **v2.2.1, 14.3 MB, 마지막 갱신 2026-07-09**가 표시돼 있다. 팔레트·패키지·간지 정보를 사용해 적재 패턴과 Job 프로그램을 자동 생성하고 위치·순서·방향·패턴을 조정하는 제품이다. [공식 HRPal 제품 페이지](https://www.hd-hyundairobotics.com/biz/product/support/287)

공식 배포 페이지의 지원 환경은 **MS Windows**, 지원 제어기는 **Hi5a·Hi5·Hi6**다. 다운로드 파일명은 `HRpal_v2.2.1.zip`이며 Hi5a용과 Hi6용 PDF 설명서 링크를 제공한다. [공식 배포 페이지](https://down-hd.web.app/en/docs/software/HRpal/)

다음 제품은 구분해야 한다.

| 이름 | 공식 설명으로 확인한 역할 |
|---|---|
| HRPal | PC에서 팔레타이징 패턴과 작업 프로그램 생성 |
| HRpalware | 제어기 티칭 펜던트(TP)에서 실행하는 앱. HRPal과 주요 기능이 유사하지만 HRSpace 프로젝트 생성 기능은 제외 |
| HRSpace | 3D 가상 작업 환경을 구성하고 시뮬레이션하는 오프라인 프로그래밍 소프트웨어 |
| Hi6 Open API / HDR Client Driver | 제어기와 통신해 상태 확인·명령·파일·궤적 등을 다루는 인터페이스. HRPal 패턴 최적화 API라는 근거는 아님 |

출처: [응용 소프트웨어 목록](https://down-hd.web.app/en/docs/software/), [HRPal 지원 정보](https://down-hd.web.app/en/docs/software/HRpal/), [공식 Hi6 Open API 문서](https://github.com/hyundai-robotics/doc-hi6-open-api), [공식 HDR Client Driver](https://github.com/hyundai-robotics/hdr_client_driver/blob/main/README.MD).

## 2. 사용설명서에서 확인한 입출력

열람 가능한 Hi5a 온라인 설명서는 챕터명이 **HRpal v1.0**이다. 최신 v2.2.1의 모든 기능과 동일하다고 가정하지 않는다. 아래는 이 공개 설명서에서 직접 확인한 내용이다.

패키지 정보에는 이름·길이·폭·높이·중량을 입력한다. 패턴 생성 화면에서 팔레트·패키지·간지를 선택하고 상자 사이 간격, 적재 시작 방향, 층수·층 처짐, 간지 삽입 조건을 지정한다. 층수는 팔레트의 중량 한도를 고려하지만 사용자가 직접 지정할 수도 있다고 설명한다. [패키지 입력](https://manual2-hd.web.app/docs/en/hi5a/fn/Hi5aPA230424FMEN4/3/2/3-2-2/), [패턴 생성 메뉴](https://manual2-hd.web.app/docs/en/hi5a/fn/Hi5aPA230424FMEN4/3/3/3-3-1/)

결과 화면은 권장 패턴과 다른 후보 패턴, 중량·높이 정보를 표시한다. 홀수층·짝수층·최상층의 패턴을 선택·변경할 수 있고 90도 회전이나 좌우 대칭 변환 및 3D 예상 형상 보기가 있다. 이 설명은 생성 결과의 UI와 편집 기능을 보여주며, 후보 생성·탐색·점수 계산의 내부 알고리즘이나 전역 최적성 증명을 제공하지 않는다. [패턴 생성 결과](https://manual2-hd.web.app/docs/en/hi5a/fn/Hi5aPA230424FMEN4/3/3/3-3-2/)

패턴 관리에서는 **Job 프로그램 또는 POSE 파일**을 생성할 수 있다. Job 생성은 지정한 폴더에 파일을 저장하고 HRSpace 시뮬레이션 환경·패키지 모델 생성을 지원한다. 문서에 HRSpace3와 HRSpace4 표기가 함께 있으므로 최신 버전 호환성은 실제 설치본에서 확인해야 한다. [패턴 관리](https://manual2-hd.web.app/docs/en/hi5a/fn/Hi5aPA230424FMEN4/3/5/), [Job 생성](https://manual2-hd.web.app/docs/en/hi5a/fn/Hi5aPA230424FMEN4/3/5/3-5-1/)

공식 예제는 HRPal과 HRSpace3를 사용해 팔레타이징·디팔레타이징 설정, 티칭 및 표준 프로그램의 동작을 확인하는 절차다. 예제 설명은 패키지 운송 시뮬레이션을 제외한다고 명시한다. 따라서 그 예제가 존재한다는 사실만으로 ALPS의 매장 재분배 시간 모델이나 실제 전체 작업시간이 검증되는 것은 아니다. [공식 시뮬레이션 예제](https://manual2-hd.web.app/docs/en/hi5a/fn/Hi5aPA230424FMEN4/5/)

## 3. 아직 확인되지 않은 부분

| 확인 대상 | 이번 조사 결과 | 비교에 미치는 영향 |
|---|---|---|
| 내부 패킹 알고리즘·탐색식·소스 코드 | 확인한 공개 자료에 없음 | Greedy·BLB·Beam·MCTS 등 임의 구현을 HRPal 알고리즘으로 부르지 않음 |
| HRPal용 공개 SDK·CLI·HTTP 패턴 생성 API | 찾지 못함 | 실제 GUI 실행 또는 제조사가 제공하는 인터페이스가 필요 |
| 박스가 한 개씩 무작위 입고할 때의 온라인 재계획 | 공개 설명서에서 확인 못함 | ALPS 온라인 조건과 동등한 입력 정보 제한으로 실행 가능한지 확인 필요 |
| 다른 치수·중량의 여러 SKU를 같은 팔레트에 자동 혼합 적재 | 최신 HRPal의 지원 여부 확인 못함 | 한 SKU 패턴 생성 설명을 근거로 지원/미지원을 단정하지 않음 |
| 동일 공개 데이터셋에서의 적재율·계산시간·재분배 비교 | 공식 수치·원시 벤치마크를 찾지 못함 | 현재 성능 표에 숫자를 채울 근거 없음 |
| 현재 ALPS의 지지·마찰·하중·접근 경로 제약과 동일한 검사 | 확인 못함 | 실제 출력을 공통 검사기로 다시 검사하고 불일치 항목을 보고 |

조사 범위는 위 공식 제품/배포/설명서 및 현대 공식 GitHub, `HRPal algorithm`, `HRPal API`, `HRpal benchmark` 등의 검색이다. “찾지 못했다”는 제조사 내부 또는 고객 전용 자료에도 존재하지 않는다는 뜻이 아니다. 공식 Hi6 통신 API가 공개돼 있다는 사실을 HRPal 최적화 엔진 공개로 바꾸어 해석하지 않는다. [Hi6 Open API](https://github.com/hyundai-robotics/doc-hi6-open-api), [HDR Client Driver](https://github.com/hyundai-robotics/hdr_client_driver/blob/main/README.MD)

## 4. 실제 설치·실행 접근 상태

공식 배포 페이지가 공개한 v2.2.1 ZIP 및 Hi6 PDF의 Firebase Storage 링크에 직접 GET을 시도했다. **둘 다 HTTP 402**를 반환했고, 응답은 해당 Firebase 프로젝트의 무료 Spark 플랜에서 Cloud Storage 제공이 중단돼 저장소 소유자가 요금제를 변경해야 한다는 내용이었다. 파일 대신 406바이트 오류 JSON이 내려왔으므로 설치 파일·PDF를 확보한 것으로 세지 않았다. 접근 실패는 프로그램 자체의 품질이나 지원 종료를 뜻하지 않는다. 출발 링크는 [공식 HRPal 배포 페이지](https://down-hd.web.app/en/docs/software/HRpal/)다.

새 공식 홈페이지의 HRPal 다운로드 버튼은 로그인 상태를 검사하고, 비로그인 상태에서는 회원 로그인이 필요하다는 안내를 표시하도록 구현돼 있다. 이번 조사에서는 로그인을 수행하거나 다운로드 접근 제한을 우회하지 않았다. [공식 다운로드 진입점](https://www.hd-hyundairobotics.com/biz/product/support/287)

따라서 이번 환경에서 **HRPal을 설치·실행하거나 실제 패턴을 생성하지 않았다.** Mac에서 작업 중이고 배포 페이지는 Windows만 지원 환경으로 표시하므로, 실제 비교에는 지원되는 Windows 실행 환경과 정상 설치본 또는 제조사/팀원이 생성한 원본 출력이 필요하다. 비공식 배포본으로 대체하거나 다른 버전을 최신판의 측정으로 표시하지 않는다. [지원 OS와 다운로드](https://down-hd.web.app/en/docs/software/HRpal/)

공식 응용 소프트웨어 페이지에는 HD현대로보틱스 로봇의 지원·교육 외 사용, 판매, 수정에 관한 제한 문구가 있다. 조사·교육용 실행과 별개로 바이너리를 저장소/공개 사이트에 재배포하는 것은 이 작업에 포함하지 않는다. [공식 배포 사용 안내](https://down-hd.web.app/en/docs/software/)

## 5. 8초 로봇 사이클과의 관계

이번 프로젝트의 **박스당 8초는 사용자가 지정한 비교 가정**이다. HRPal의 보장 성능 또는 HD현대로보틱스 전 기종의 공식 사이클 시간이라는 근거를 찾지 못했다.

예를 들어 공식 HDP160-31(HP160) 페이지는 160 kg 가반, 3,128 mm 작업범위, 4축 구조, 축별 최대 속도 등을 제공한다. 이 사양은 특정 상품·그리퍼·픽업점·적재점·신호 대기를 포함한 완전한 8초 사이클의 보증값이 아니다. [공식 HDP160-31 사양](https://www.hd-hyundairobotics.com/biz/product/detail/34)

공정한 **배치 알고리즘 비교**에서는 양쪽 모두 동일한 `1박스=8초` 가정을 적용하고 계산·인식의 겹침 규칙과 팔레트 교체 시간을 맞출 수 있다. 이때 HRPal이 더 짧은 로봇 경로를 만든다는 이득은 고정 시간 모델에 나타나지 않는다. 실제 로봇 속도까지 비교하려면 같은 모델·제어기·그리퍼·레이아웃에서 얻은 HRSpace 또는 실장비의 검증된 동작시간을 양쪽 모두에 적용하는 별도 시험이 필요하다. 이는 비교 설계에 대한 권고이며 HRPal이 해당 평가를 통과했다는 주장이 아니다.

## 6. HRPal을 실제 평가에 넣는 방법

권장 방식은 내부 코드를 흉내 내는 것이 아니라 **공식 설치본의 결과를 받아 공통 평가기로 검증하는 블랙박스 비교**다. 아래는 이 프로젝트의 권고 인터페이스다.

| 결과 필드 | 필요한 내용 |
|---|---|
| 출처 | 제품명, 정확한 버전, 설치본 해시, 실행 OS·장비, 실행일, 원본 파일명 |
| 입력 | 주문 ID, SKU별 치수·중량·수량, 팔레트 규격·최고 높이·허용 중량, 허용 회전, 동일 로봇/공구 제약 |
| 정보 제공 범위 | 전체 주문·미래 입고 순서를 알고 생성했는지, 현재 상품·잔량만 알고 생성했는지 |
| 운영 조건 | 버퍼/정렬 공간, 입고 재정렬 여부, 사용·출하 팔레트 수, 간지 사용, 수동 편집 유무 |
| 출력 | 박스 ID별 팔레트 ID, 적재 순서, 위치·회전·치수, 누락/미배치 사유, 원본 JOB/POSE/프로젝트 |
| 시간 | 자동 생성 계산시간, 입력·수동 편집시간, 파일 변환시간을 구분. 실제 측정하지 않은 시간은 `null` |
| 좌표 변환 | 단위, 팔레트 원점, TCP와 박스 기준점 차이, 회전 규약, 높이 기준을 기록 |

현재 공통 검사기의 수량 보존·경계·겹침·높이·지지·하중·근사 로봇 경로를 적용한 뒤, 같은 매장 정책으로 재분배를 재계산한다. 원래 HRPal 배치를 통과시키기 위해 좌표를 옮기면 수정한 배치임을 별도로 표시한다. 수동 최적화한 HRPal 결과라면 ALPS에도 같은 정보·운영 자원을 허용하거나 수동 조작 시간을 분리해 제시한다.

평가는 지원 범위에 맞춰 구분해야 한다.

1. **규격 상품의 오프라인 패턴 비교:** 동일 SKU·팔레트·층/높이·간지 조건을 양쪽에 알려주고 HRPal의 실제 생성 좌표와 ALPS의 배치를 비교한다. 두 방식 모두 미래 주문 정보를 동일하게 받는다.
2. **혼합 SKU 무작위 온라인 비교:** HRPal에서 실제로 이 운영을 지원하고 같은 정보 제한을 지킬 수 있는지 확인한 뒤 수행한다. 지원이 확인되지 않으면 `미평가/지원 확인 필요`로 표시한다. HRPal에 임의로 SKU별 별도 팔레트를 강제하거나 무제한 사전 정렬을 허용한 뒤 ALPS와 같은 시험이라고 하지 않는다.
3. **사용자 지정 8초 파이프라인 비교:** 실제 출력과 실제 계산 측정값을 입력하고, 양쪽에 동일한 운반·교체·후단 조건을 적용한다. 패턴 전체를 미리 계산한 준비시간과 온라인 박스당 판단시간을 같은 지표로 섞지 않는다.

이 인터페이스를 구현해 두면 팀원이 Windows HRPal에서 만든 프로젝트·JOB/POSE·계산 기록을 가져와 공통 시뮬레이션 장면과 적재율·재분배 표에 넣을 수 있다. **실제 원본을 확보하기 전에는 HRPal 행의 적재율·속도·순위를 비워 두어야 한다.**

## 7. 발표에 사용할 수 있는 현재 문구

> “산업용 비교 대상으로 HD현대로보틱스 HRPal을 조사했습니다. 공식 제품은 적재 패턴과 로봇 작업 프로그램을 생성하며, 실제 출력물을 같은 제약·후단 모델로 평가하는 절차를 준비했습니다. 현재는 프로그램 실행 결과를 확보하지 못해 HRPal 대비 성능 우월성을 주장하지 않습니다.”
