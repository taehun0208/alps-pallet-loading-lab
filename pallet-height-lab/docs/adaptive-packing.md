# 변형·관측 오차 적재 실험 구현 기록

기존 프로젝트를 교체하지 않고 `src/pallet/adaptive/`에 실험 모듈을 추가했다. 기존 적재·포장·4대 로봇 협업 화면과 알고리즘은 유지한다. 새 화면은 `?palletView=adaptive#pallet`로 연다.

## 실행과 조작

```powershell
cd outputs/tetris-ai-lab
npm run dev
# http://127.0.0.1:5173/?palletView=adaptive#pallet
npx vitest run tests/pallet-adaptive.test.ts tests/pallet-adaptive-ablation.test.ts
npm run build
```

1. 알고리즘, 환경, 시드, 물량, 높이, 변형·재료 조건을 고른 뒤 **조건 적용 · 새 실행 준비**를 누른다.
2. 실행 / 일시정지 / 한 단계 / 초기화를 사용한다. 조건 적용·초기화·비교 취소는 기존 Worker를 종료한다.
3. 박스를 클릭하거나 오른쪽 선택기로 질량·손상·하중·지지·흡착·관측 오차를 조회한다. 반투명·접촉·흡착 영역·관측 윤곽·경로·탈락 후보를 켤 수 있다.
4. **A/B/C · 3개 시드 비교**는 현재 시드와 다음 두 시드를 사용한다. JSON에는 입력, 설정, 결과, 로그가 담긴다. CSV에는 측정 요약이 담긴다.
5. 개별 박스의 직접 허용하중, 질량중심, 마찰, 손상 마스크, 복합 형상은 **입력 JSON → 현재 입력 불러오기 → 수정 → 입력 적용**으로 설정한다. 알 수 없는 강도는 `topLoadKg:null, source:"unknown"`이다.
6. 새 기능을 전혀 사용하지 않으려면 기존 적재 또는 4대 로봇 협업 탭을 사용한다. 기존 입력·기능과 렌더러는 변경하지 않았다.

## 형상·질량·강도

정상 직육면체는 1개, 변형은 기본 4×4 바닥 격자에 대한 복합 직육면체로 근사한다. 모서리 눌림은 코너 기둥의 폭·높이, 윗면 함몰은 가운데 기둥의 높이, 옆면 돌출은 외곽 기둥의 폭, 불균일 바닥은 기둥별 바닥 높이에 반영한다. JSON에서는 다른 복합 형상을 입력할 수 있다. 곡면/얇은 종이 굽힘을 정밀 재현하는 메시나 FEM은 아니다.

같은 `parts`를 **화면·충돌·접촉·부피·흡착 표면**에 사용한다. 접촉 판정용 박스를 임의로 축소하지 않는다. 코너 손상 등에서 외형 부피가 줄어드는 것은 해당 합성 형상 자체가 변했기 때문이며, 충돌체도 동일하다.

- nominalVolume = 정상 w×d×h.
- occupiedVolume = 현재 복합 직육면체 **합집합의 외형 체적**. z 절편마다 xy 합집합 면적을 적분한다. 종이 재료 부피가 아니다.
- envelopeVolume = 현재 허용 방향에서 복합 형상을 감싼 AABB 체적.
- 구멍·찢김은 **상면 흡착 금지 마스크**다. 실제 관통 구멍 충돌체나 균열 역학은 구현하지 않았으므로 이 마스크는 부피나 강도를 자동으로 줄이지 않는다.

`mass`, `com`, `strength`는 독립 입력이다. 변형량만으로 CoM이나 잔여강도를 바꾸지 않는다. 기본 CoM은 정상 규격 중심이라는 명시적 가정이고, 실제 편심 질량은 JSON의 `com`으로 입력한다. 합성 직접 허용하중은 15~90 kg, 4개 중 1개는 잔여강도 0.8을 가정한다. 논문에서 얻은 보편 상수가 아니다. 실측 출처 입력도 가능하다. ECT/BCT 자동 환산은 구현하지 않았다.

## 계획기·필수 제약·점수

A/B/C는 실제 박스 목록·물성·순서·환경·높이·오차 시드와 **동일한 실제 실행 판정기**를 사용한다. 계획기에는 현재 도착한 버퍼 관측값과 배치된 관측 장면만 전달한다. 미도착 목록·실제 parts는 계획기에 전달하지 않는다.

- **A**: 기존 Greedy `plan`을 현재 박스 모드로 호출한다. 기존 정상 규격 직육면체 후보·평가를 보존한다. 새 실제 판정기는 A가 제안한 충돌·하중·집기 불가 배치를 거절할 수 있다.
- **B**: 변형 관측 형상, EMS/상면, 지지·전도 제약. 버퍼 선두 순서. 흡착·경로·하중을 선택 제약으로 사용하지 않는 비교군이지만 실제 실행에서는 공통 판정으로 모두 검사한다.
- **C**: B + 하중·흡착·경로 제약, 제한 버퍼 순서 선택, 대기/재시도 비용, 재관측·재계획.

A의 어댑터는 전체 미래 재고를 공개하지 않는 별도 비교 조건이다. 과거 연구용 전체 재고 선택 모드의 결과와 동등한 온라인 비교라고 주장하지 않는다. 그 모드는 기존 탭에 그대로 남아 있다. 정상 박스 8개의 다층 순서에서 기존 계획기와 새 A 어댑터의 위치·회전이 일치하는 테스트를 포함했다.

EMS는 점유 envelope를 빼서 생성하는 최대 빈 직육면체 유사 표현이다. 겹치는 빈 공간을 허용하지만 포함된 공간은 제거한다. 최대 80개를 유지하며 직육면체 안 모서리와 실제 상면 경계를 후보로 삼는다. 경계/형상 충돌을 빠르게 제거한 뒤 최대 64개/상자를 정밀 평가한다. EMS envelope 자체가 보수적이므로 일부 불규칙한 빈 공간은 놓칠 수 있다. 최적해 보장은 없다.

경계, 관통, 지지율, 큰 무지지 틈, 합력 전도, 누적 허용하중, 회전, 흡착, 경로 위반은 유효 후보 선택 전 배제한다. A/B 및 C 토글 해제는 의도적인 계획기 ablation이며 **실제 판정의 제약은 해제하지 않는다**. 실패를 점수로 상쇄해 실행하지 않는다.

점수 성분은 [0,1]로 제한하고 가중합/가중치합으로 정규화한다. A의 기존 점수만 원래 단위를 그대로 표시한다. 기본 가중치:
높이 3 / 잔여공간 2 / 지지 2 / 하중 1 / 경로 1 / 흡착 1 / 대기 1 / 재시도 비용 0.5 / 후속 받침 2.
잔여 공간 점수는 가장 큰 빈 체적과 **도착한 다른 박스**의 envelope 적합률이다. 후속 받침 점수는 평평한 상면·면적·낮은 위치의 기하 선호다. 둘 다 후속 물리 성공의 보장은 아니다.

## 지지와 누적 하중

접촉 높이 오차 0.5 mm와 관통 허용오차 0.05 mm를 분리했다. 접촉 직사각형을 좌표 절편으로 분할하고 겹친 부분을 한 번만 계산한다. 최소 지지율 0.8, 무지지 직선 간격 180 mm, 지지 볼록껍질 안 합력 여유 2 mm는 사용자 조절 가능한 설계 가정이다.

지지 관계를 DAG로 구성하고 위에서 아래로 처리한다. 자중 + 전달된 상부하중의 합력 작용점을 계산한다. 각 접촉 직사각형 코너에 비음수 반력을 놓고 힘 합과 x/y 모멘트 평형을 만족하는 기존 solver를 사용한다. 면적 비례 압력을 시작점으로 사용하지만, 단순 면적 배분만 하는 것은 아니다. 음의 반력이 필요하거나 합력이 지지 영역 밖이면 거절한다.

각 상부하중 kg와 자중 포함 반력 kg 상당을 구분한다. N = kg 상당 × 9.80665. 허용 상부하중 = 직접 입력값 × 명시적 잔여강도. 알 수 없는 하부 용량에 양의 상부하중을 올리면 거절한다. 최종 힘·모멘트 잔차도 내보낸다.

반력 분포는 강체 정적 근사다. 골판지 패널 굽힘/좌굴, 압력 국부 집중, 시간 의존 크리프, 운송 가속도/진동까지 검증하지 않는다. 접촉 면적/CoM만으로 실물 안정성을 보장한다고 표시하지 않는다.

## 흡착과 이동

객체 ID/형상 식별은 시뮬레이터가 제공하고, 잡을 점은 별도 기하 함수가 선택한다. 기본 컵 지름 50 mm + 가장자리 여유 8 mm의 **컵을 포함하는 정사각형 전체**를 평가한다. 복합 상면 경계로 세분한 모든 영역의 높이 범위(기본 1.5 mm), 경사 상한 10°, 모서리·손상 마스크, CoM 레버암을 검사한다. 한 점만 평평한지는 사용하지 않는다. 컵 원 대신 정사각형을 쓰므로 보수적이다.

기본 질량 한도 35 kg, 모멘트 한도 12 N·m, 그리퍼 100×100×100 mm, 아래 여유 2 mm, 이동속도 850 mm/s. 모두 수정 가능한 프록시 가정이다. JSON의 개별 suction 한도와 공통 그리퍼 한도 중 작은 값을 사용한다.

실제 판정은 계획기가 지정한 흡착점만 확인한다. 실제 정답 형상에서 다른 좋은 점으로 몰래 바꾸지 않는다. 명령한 접촉 높이가 실제 높이와 접촉 허용오차 이상 다르면 집기 기하 실패다. 진공·재질 투과성·밀봉을 모델링하지 않으므로 `physicalPickSuccessRate:null`로 저장한다.

접근→집기→상승→안전 높이 yaw→x/y 이동→하강→놓기→후퇴. 평행이동은 각 복합 part와 그리퍼의 swept AABB를 검사한다. 90° 회전은 안전 높이에서 보수적 회전 envelope로 검사한다. 안전 높이 = 환경/점유 높이 + 150 mm. 작업공간 상단 2600 mm를 넘으면 거절한다. 실제 팔 관절·IK·케이블·그리퍼 진공 배관은 포함하지 않는다. 프록시 이동시간에는 거리/속도, 집기·놓기 총 2 s, yaw 0.5 s만 반영한다.

## 환경과 관측/실행 경계

팔레트는 벽 0개다. 롤테이너는 왼쪽/오른쪽/뒤 벽을 각각 선택한다. 벽은 충돌·접근 장애물이며, 측면 반력을 모델링하지 않으므로 마찰 지지로 사용하지 않는다. 앞쪽 채우기는 점수 선호만 바꾼다.

실제 Box/Placed는 실행기가 보관한다. 관측은 도착 시 생성하고 박스 ID·시드·관측 revision에 따른 재현 가능한 균등 잡음을 사용한다. 치수·위치·표면 mm, yaw °를 개별 설정할 수 있고 기본 0이다. 관측 yaw는 회전 part의 보수적 AABB로 변환한다. 이는 실제 기울어진 연속 메시 해석이 아니다. 각 알고리즘의 첫 관측은 같고, 재관측 횟수가 달라지면 같은 잡음 생성 규칙의 해당 revision을 사용한다.

버퍼 6개를 채우고 C는 그 안에서만 선택한다. 배치 실패 시 실제 장면은 바꾸지 않고 중단·재관측·재계획한다. 성공 시 배치 장면 전체를 재관측한다. 재시도 기본 2회, 대기 최대 8판단. 버퍼가 차면 입고를 멈추고, 모두 불가하면 제한 재시도 후 미배치로 분류하여 다음 입고를 받는다. 미래 박스를 무제한 미리 보지 않는다. 대기 수치는 벽시계 초가 아니라 판단 tick이다.

기하 정렬 실험은 기본 OFF이며, 켜면 최대 8 mm 수평 offset 9개를 실행 판정기로 검사한다. 상자를 줄이거나 충돌을 무시하지 않는다. 이것은 **힘 제어 순응이 아니다**. 접촉력 한도·실물 그리퍼 유연성 검증은 구현하지 않았으므로 기본 기능으로 주장하지 않는다. 힘 제어 실행기는 adapters.ts의 후속 연결 대상이다.

현재 실행은 기존 박스를 접촉으로 움직이거나 소성 변형시키지 않는다. 따라서 주변 박스 이동을 수치 해석한 것으로 표현하지 않는다. 외부 관측 공급자는 변경된 장면을 반환할 수 있고 다음 재계획에서 장면 전체의 점유·지지를 재구성한다.

## 검증

50개 테스트 통과: 새 핵심 16개 + ablation/잡음 비교 1개 + 관련 기존 회귀 33개. 빌드/TypeScript 통과. 기존 테스트 전체 55개 파일을 모두 실행한 것은 아니다.

핵심 사례:
1. 기존 정상 박스 후보 및 8개 다층 위치·회전 재현.
2. 옆면 돌출 시 정상 규격에서 통과하던 경계 배치를 거절; 세 부피 구분.
3. 작은 접촉·5 mm 부양 거절.
4. 겹친 접촉 면적 합집합과 두 받침의 힘/모멘트 보존.
5. 3층 누적 상부하중으로 맨 아래 과부하 거절.
6. 명시적 편심 CoM 및 상부 합력에 의한 전도 감지.
7. 중앙 찢김과 비중앙 전체 컵의 적합성 구분.
8. 최종 위치가 비어 있어도 위 장애물로 하강 경로 거절.
9. 팔레트에 벽이 없고 롤테이너도 측면 지지를 가정하지 않음.
10. 잡음·재계획의 동일 시드 재현 및 유한 종료.
11. 형상과 강도/CoM 독립, 미확인 하부 강도 거절.
12. 실제 선택점이 나쁘면 다른 좋은 흡착점으로 대체하지 않음.
13. 잘못된 입력 거절, yaw에 따른 외형 부피 보존.
14. 동일 실제 입력 A/B/C 다중 시드 결과 저장.
16. FIFO에서 아직 검사하지 않은 대기 박스를 시간만으로 탈락시키지 않음.
15. 입력 SHA256 일치 확인을 포함한 기능 제거/잡음 실험.

브라우저에서는 1920×1080 실행 화면, 조건/높이 적용 후 한 단계, 비교 및 파일 내보내기, 모바일 레이아웃을 확인한다. 계산은 Worker에서 수행하며 사용자 취소 시 terminate한다. 시간 상한에 닿으면 일부 후보만 본 결과임을 기록한다. 고정 후보 수 이하에서 완료한 테스트는 결정적이며 wall-clock 상한이 걸리는 느린 장치에서는 선택이 달라질 수 있다.

## 한계와 후속 확장

- 잡음 조건에서는 보수적인 관측 AABB와 엄격한 접촉/경계 검사가 유효 배치까지 거절할 수 있다. 아래 잡음 실험 결과를 숨기지 않는다. 현재 구현을 관측 오차에 강건한 산업 검증 완료 제품으로 부르지 않는다.
- 자동 물체 인식·진공 밀봉·실물 재료 강도 추정·FEM·유연체 변형·운송 동역학·IK·힘 제어는 미검증이다.
- 현재 형상은 소규모 복합 직육면체 근사다. 곡면·임의 roll/pitch, 정밀 표면 압력, 옆면 흡착, 복잡한 끼워넣기는 후속 과제다.
- EMS와 후보 예산은 일부 가능한 틈을 놓친다. 입고 버퍼 안 기하 휴리스틱이며 전역 최적해 증명이 아니다.
- 다음 우선순위는 오차 구간을 유지하는 관측 융합, 보수 경계와 접촉 오차의 분리, 복수 관측의 형상 추정, 실물 컵 밀봉 모델, 접촉력 제한 실행기, 방향별 실측 BCT 및 동적 검증이다.
- 공개 4대 로봇 컨베이어 알고리즘은 유지했다. 새 변형 모델을 그 다중 로봇 시간 스케줄러에 자동 이식한 것은 아니다. 검증이 분리된 새 실험 탭에서 비교한다.
