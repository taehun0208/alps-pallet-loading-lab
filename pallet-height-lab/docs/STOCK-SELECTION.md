# 재고 선택 · 받침을 먼저 만드는 적재

2026-10-04. 기존에는 위치만 결정할 수 있었습니다. 도착 박스가 불안정하면 뒤의 튼튼한 박스를 먼저 꺼낼 권한이 없어 중단했습니다. 이번 기본 모드는 **전체 입력 재고를 실제로 선택할 수 있다고 가정**하며 순서와 위치를 함께 결정합니다. 임의 도착을 그대로 처리하는 모드도 별도로 유지합니다.

## 한 단계

1. 미확정 재고의 모든 종류를 검사합니다. 반복 규격의 개별 ID는 하나씩 소비합니다.
2. 종류별 최대 16개 위치를 기하·지지·반력·하중·기둥 조건으로 검사합니다. 현재 놓이지 않는 종류는 재고에 보류합니다.
3. 넓고 낮은 받침과 박스별 유효 허용 하중을 평가합니다. 남은 박스 중 그 받침의 치수 안에 들어가고 허용 하중 이하인 물량을 부피로 가중합니다. 종이/플라스틱이라는 이름 대신 입력 하중 값을 사용합니다.
4. 즉시 평가와 받침 기회로 상위 3종을 남기고 종류별 최대 24개 위치에서 잔량 공간을 상세 평가합니다. 기본 배치는 우선 종류 안에서 잔량 적합 비중을 보존한 낮은 위치, Greedy는 합산 점수, Rollout은 선택 후보의 후속 재고 선택 최대 2단계까지 계산합니다.
5. 선택 ID와 위치를 저장하고 확정 시 그 박스 하나만 재고에서 뺍니다. 확정 좌표는 유지하고 다음 단계에서 보류한 종류도 다시 검사합니다.

받침 보상은 남은 적합 물량 비중 75%와 팔레트 대비 받침 면적 25%를 조합하고 높이/폭과 배치 높이를 반영합니다. 현재 부피에도 작은 보상을 줍니다. 이는 하드 제약을 통과한 후보의 제한된 평가이며 전역 최적해를 보장하지 않습니다. 원래 지지율 95%, 돌출 0 mm, 균일 내부 질량, 정적 힘/모멘트·하중 검사와 그리퍼 폭 제외를 유지했습니다.

**한 종류가 놓이지 않는 것과 전체 재고에 유효 후보가 없는 것을 구분합니다.** 첫 상황은 보류 후 계속합니다. 마지막 상황에서만 미적재 잔량과 사유를 표시합니다. 희소 위치 탐색의 실패는 전체 연속 공간에서 불가능하다는 증명이 아닙니다. 순서 재선택으로 들어갈 수 없는 모든 입력을 반드시 적재한다고 주장하지 않습니다.

## 알고리즘 먼저 실행

177×211×417 mm 긴 박스는 높이/받침 비율 때문에 바닥에 바로 놓이지 않습니다. 503×407×97 mm 받침을 뒤에 둔 도착 순서 입력은 첫 단계에서 실패했습니다. 동일한 박스의 재고 선택은 받침→긴 박스 순서로 2/2개를 적재했습니다. 받침을 강한 종이로, 긴 박스를 약한 플라스틱으로 바꿔도 입력 허용 하중으로 올바르게 선택했습니다.

## 화면과 데이터

기본 ‘박스 공급 방식’은 **재고 선택 · 받침부터 배치**입니다. 도착 순서 모드는 기존처럼 다음 입고 시드를 사용합니다. 재고 선택은 입고 시드를 사용하지 않으며, 같은 박스 구성·계획기 설정으로 같은 선택을 재현합니다. 새 랜덤 재고를 생성해도 공급 모드를 유지합니다.

미확정 선택 박스는 아직 재고에 포함합니다. 확정 후에만 수량을 줄입니다. 실행 JSON에는 `supplyMode: stock-select`, 단계별 선택 ID, 검사 종류 수, 보류 이유를 저장합니다. 선택 프레임을 재생하거나 취소해도 수량을 다시 소비하지 않습니다. 과거 JSON에서 supplyMode가 없으면 도착 순서 모드로 해석합니다. 단계별 손상/누락 이벤트는 도착 순서 모드에서 실행합니다.

```powershell
npm.cmd test -- --exclude '**/*benchmark*'
npm.cmd test -- tests/pallet-stock-benchmark.test.ts
npm.cmd run build
npm.cmd run test:browser -- tests/pallet-stock-browser.spec.ts tests/pallet-browser.spec.ts --retries=0
```

재질·무게·강도 생성값은 합성 입력입니다. 실제 포장 압축·로봇 접근·운송 안전을 보증하지 않습니다. 재고 선택 모드를 실물에 적용하려면 해당 박스를 실제로 먼저 꺼낼 수 있는 공급 환경이 필요합니다.
