# Pallet Loading Lab · 온라인 혼합 적재

현재 입고된 박스의 위치와 자세를 결정하는 브라우저 시뮬레이터입니다. 학습 모델·LLM·외부 API 없이 후보 생성, 하드 제약, 잔량 위치 검사와 짧은 가상 탐색으로 동작합니다. 요구사항의 대응과 사전 시험/보완 과정은 [온라인 알고리즘 보고서](docs/ONLINE-MIXED-PALLETIZING.md)에 있습니다.

## 실행과 과제 조건

프로젝트 폴더에서 `START-PALLET.cmd`를 실행하거나 다음 명령을 사용합니다.

```powershell
npm.cmd ci
npm.cmd run dev
```

[팔레트 시뮬레이터](http://127.0.0.1:5173/#pallet)를 엽니다. 기존 2D는 `/`, 테트라큐브는 `/#3d`입니다. Worker와 ES 모듈을 사용하므로 정적 서버에서 제공해야 합니다.

새 화면은 **과제 조건 · 무작위 혼합 박스 30개**, 공급 **순차 투입 / 버퍼 없음**, 평가 **온라인**, 알고리즘 **Greedy**입니다. 기존 입력을 유지하면서 새 조건을 적용하려면 **이 입력에 과제 조건 적용**을 누릅니다. 현재 박스 세트·팔레트·그리퍼 숫자를 유지하고 순차 공급, 무게 순서 each, 그리퍼 근사, 새 평가를 켜며 새 실행을 시작합니다. 이전 실행은 보관됩니다.

온라인 모드에서 다른 검증 예제를 선택해도 무게 순서와 로봇 검사 기본은 유지됩니다. 전체 재고 연구를 선택하거나 설정에서 명시적으로 변경하면 연구 조건이 표시됩니다.

왼쪽 **현재 적용된 검사** 패널을 확인하세요. 체크는 해당 검사 활성화 표시입니다. 모든 배치의 통과나 실제 로봇의 안전 인증을 뜻하지 않습니다. 설정을 바꾸면 연구 조건 또는 제외된 검사를 표시합니다.

## 로봇팔 동작 보기

[로봇팔 예제](http://127.0.0.1:5173/?palletDemo=robot#pallet)는 기존 6자세 혼합 입력을 실제로 계산하고 실행합니다. **로봇 작업셀**은 팔·입고대·팔레트를 함께 보여줍니다. **입체**는 팔레트 중심 시점입니다.

- **로봇팔** 체크로 표시를 켜거나 끕니다. 이상적 적재 모드에서는 팔과 그리퍼를 숨깁니다.
- **자동 적재 / 한 단계 / 일시정지 / 계속 재생 / 재생 속도**는 그리퍼와 관절에 함께 적용됩니다. 손목은 가로·세로 회전과 옆면 세우기 방향을 따릅니다.
- **가상 로봇팔 · 길이와 설치 위치**에서 X/Y 설치 좌표, 어깨 높이, 상완/전완 길이를 바꿉니다. 표시 설정으로, 계획기 입력이나 확정 적재 결과를 바꾸지 않습니다.
- 팔이 닿지 않으면 **도달 불가**와 실제 팔 끝부터 목표 그리퍼까지의 빨간 점선을 표시합니다. 팔 길이를 늘려 맞추지 않습니다.
- 빨간 링크와 **간섭 근사**는 현재 자세의 링크와 계획 박스·바닥 사이 간섭 가능성을 뜻합니다. 적재 경로를 자동으로 우회하거나 실행을 중단시키지는 않습니다.

표시용 팔은 고정 길이 해석 기구학을 사용합니다. 기존 계획기의 TCP 작업영역과 별도이며, 실제 로봇 기종의 관절 한계·자기 충돌·운반 박스/입고대/팔레트를 포함한 전체 경로 충돌·토크·흡착은 검증하지 않습니다. [상세 범위와 시험](docs/ROBOT-ARM.md).

## 혼합 재고의 공간 채우기

[내부 빈틈 · 6자세 랜덤 30개 실행](http://127.0.0.1:5173/?palletDemo=spatial#pallet) 또는 [혼합 규격 8종 48개 실행](http://127.0.0.1:5173/?palletDemo=mixed#pallet)을 엽니다. 전체 재고 선택이 가능한 조건에서 박스·자세·위치를 함께 선택합니다. 원래 높이를 유지하는 0/90°뿐 아니라 깊이축 또는 가로축을 수직으로 세우는 자세를 지원합니다.

**옆면 세우기 허용 · 새 실행**은 현재 재고와 제약을 유지하고 허용 자세를 확장합니다. **현재 재고 모아서 실행**은 현재의 박스별 허용 자세를 유지합니다. **랜덤 혼합 재고 실행**은 새 재고에도 현재의 세우기 허용을 적용하며 이전 실행은 보관합니다. 위아래 유지 박스는 세우지 않습니다.

**팔레트 · 박스 편집**에서 6개 자세를 개별 선택하고 방향별 상부 하중을 입력할 수 있습니다. 비어 있는 방향은 공통 강도가 적용된다는 가정입니다. 자세마다 실치수·무게중심·지지·하중을 다시 검사하며, 그리퍼 모드에서는 안전 높이에서 세우는 회전 공간과 옆면 이탈도 검사합니다.

**내부 공간과 박스 자세**에서 높이대별 외곽 안의 빈 부피와 세운 박스 치수를 확인합니다. **배치 이력**, **지지 면**, **물리 검증 실행**으로 실제 프레임을 분석합니다. 기본 30개는 주변 높이 맞춤 조건에서 16개·964mm·내부 채움 87.5%입니다. 모든 박스의 적재나 최적성을 보장하지 않습니다. 다른 랜덤 입력의 적재 수 감소도 [높이 맞춤 보고서](docs/STANDING-HEIGHT.md)에 기록했습니다.


## 세로 박스의 높이를 주변 층과 맞추기

**적재 제약 · 환경**에서 **세로 박스 주변 높이 맞춤**을 켜고 최대 돌출 mm를 설정한 뒤 새 실행에 적용합니다. 기본은 100mm이며, 박스 높이의 25%보다 더 높게 솟는 것도 제한합니다. 바닥 짧은 변보다 높이가 1.25배를 넘는 실제 세로 형상에 적용합니다. 가깝고 옆면 길이가 충분히 겹치는 눕힌 박스를 기준으로 삼으며, 다른 세로 기둥은 기준으로 쓰지 않습니다.

재고 선택 모드는 주변 층을 먼저 쌓고 세로 박스를 다시 검토합니다. **내부 공간과 박스 자세**의 높이 비교에서 박스/이웃 상단과 돌출값을 확인하세요. 버퍼 없는 순차 투입은 현재 박스가 조건을 만족하지 못하면 멈춥니다. 이전 방식 재현은 이 조건을 명시적으로 끄며 JSON과 보관 실행에 설정이 함께 남습니다. [같은 세 입력 결과와 적용 범위](docs/STANDING-HEIGHT.md).

## 입력과 사용법

- 기본 개별 박스 30개의 가로 150~760, 깊이 120~560, 높이 90~460 mm를 독립 추첨합니다. 치수를 격자 단위나 팔레트에 맞추지 않습니다.
- **랜덤 박스 세트 · 순서**에서 세트/입고 시드, 개수, 축별 범위를 지정합니다. 개별 박스 또는 여러 규격의 반복 수량을 선택할 수 있습니다.
- **재고·입고 모두 랜덤**, **이 시드로 세트 생성**, **입고 순서만 랜덤**으로 각각 새 입력·재현·동일 재고의 다른 순서를 만듭니다. 현재 적용된 팔레트와 제약은 새 세트 생성 때 유지됩니다.
- **한 단계 / 자동 적재**로 실행하고 이력 슬라이더·프레임·관측된 도착 버튼으로 과거를 봅니다. 실제 미래 순서는 미리 공개하지 않습니다. 남은 수량과 다음 추첨 확률은 현재 박스를 제외한 잔량 기준입니다.
- 후보를 선택하면 실제 좌표·점수·지지·하중·잔량 후속 위치 검사와 탈락 사유를 확인합니다. 상세 평가를 하지 않은 후보는 현재 배치 검사만 완료라고 표시합니다.
- 확정 상자를 클릭해 지지 부모·반력 작용점·하중·강도 출처를 확인합니다. 무게중심 표시에서 금색은 전체 중심, 청록은 아랫단 하중 중심, 십자는 받침 중심입니다.
- 치수·중량·재질·허용 상부 하중·강도 보정·마찰·위 적재 금지를 개별 편집하거나 JSON으로 가져올 수 있습니다. 최대 120종/120개입니다.
- 생성 중량·강도·마찰은 **합성 예제값**입니다. 같은 재질에도 다른 값을 주며, 실제 제조사/시험 입력이 우선합니다.
- 단면·층 분리·투명도·재질 색상은 계획 좌표를 바꾸지 않습니다. 같은 입력으로 세 정책을 비교하고 JSON/CSV/PNG로 저장합니다.

## 실행 중 수정과 조건별 분석

- 현재 판단의 **현재 관측 수정 · 부분 재계획**에서 실제 치수·손상·누락을 입력합니다. 미확정 동작을 취소하고 확정 박스·ID·수량·실제 입고 순서는 유지합니다.
- 왼쪽 편집에서 팔레트·제약을 바꾼 뒤 **확정 적재 유지 · 조건 재계획**을 누릅니다. 새 조건이 확정 박스를 위반하면 변경을 거절합니다. 박스 세트·수량·입고 시드 변경은 기존 **새 실행**을 사용합니다.
- 재계획 전 실행은 보관하고 각 과거 프레임에는 당시 팔레트·제약을 표시합니다.
- **적재 패턴 평가**는 물량 적재 비율과 공간·하중 균형·전도/하중 여유·작업/계산 시간을 함께 평가합니다. 제약 위반이나 강도 미검증은 점수를 주지 않습니다.
- 알고리즘 비교를 완료하면 **조건별 비교 기록**에 입력·제약·결과를 보존합니다. 조건을 바꾸고 다시 비교하면 나란히 볼 수 있으며 **조건별 비교 JSON 저장**으로 재현 정보를 내보냅니다.
- 그리퍼 회전 속도와 **TCP 도달 반경 검사**를 편집할 수 있습니다. 파지 방향은 안전 높이에서 회전하고 중간 외곽도 검사합니다. 도달 반경은 직선 경로 전체에 적용하는 근사이며 관절·IK 검사와 구분합니다.

[추가 요구사항·점수 정의·시험 입력](docs/MIXED-PALLETIZING-REQUIREMENTS.md)에 세부 근거가 있습니다.

## 알고리즘

현재 박스의 모서리·받침 중앙·하중 균형 상쇄 위치 등을 만들고 위쪽 착지를 계산합니다. 기본 최대 96개 후보를 검사하고 Greedy/Rollout은 최대 6개 다양한 상세 후보를 평가합니다. 잔량은 종류별 기본 8곳의 후속 위치에 **같은 전체 제약**을 적용합니다. 이 숫자는 탐색 범위에서 수정할 수 있습니다. 위치 표본의 유효 비중은 전체 잔량 적재 성공 확률이 아닙니다.

1. **BL:** 유효 현재 후보 중 낮은 상단 높이/y/x/방향. 잔량 검사는 결과 진단입니다.
2. **Greedy · 기본:** 상세 후보 중 후속 위치를 잃는 물량 최소, 이후 공간·아랫단 중심·작업 시간 등의 품질 점수.
3. **Rollout:** 잔량 수량으로 만든 같은 가상 순서 4개 × 최대 3단계. 후속 공간 손실/가상 막힘/추가 적재/점수 순서로 선택하며 고정 인과적 후속 정책을 사용합니다.

가상 순서는 실제 입고 난수와 독립이고 재고 수량을 초과해 뽑지 않습니다. 실제 미래 이벤트도 계획기에 공개되지 않습니다. 후보 예산과 근사 탐색이 있으므로 최적해나 연속 공간의 배치 불가능성을 증명하지 않습니다.

## 과제 기본의 제약

균등 내부 질량, 바닥 0/90° 회전, 팔레트 한 개, 돌출 0 mm, 정상 박스 버퍼 없음, 확정 좌표 유지입니다. 경계·관통·높이·95% 지지·중심 투영·수직 힘/모멘트·모든 조상 허용 하중·합력 중심의 전도 여유를 검사합니다.

상자 자체 중량은 **모든 직계 받침의 자체 중량 이하**여야 합니다. 재질 압축 강도가 충분해도 이 규칙을 위반하면 탈락합니다. 플라스틱이라는 이름만으로 강도를 확정하지 않습니다. 판지보다 약한 플라스틱 입력도 가능합니다.

높이/받침 폭은 과제 기본에서 점수 지표입니다. 접촉면 합력 중심과 전도 여유는 하드 제약입니다. 필요하면 **기둥 비율 하드 제한**을 켤 수 있습니다. 기본 여유 비율 10%, 횡가속도 가정 0.15g, 상부 하중 여유 계수 1.25이며 설계 가정입니다. 측면 접촉을 구조 결속으로 보지 않습니다.

기본 로봇 근사는 그리퍼/운반 박스의 스윕, 위쪽 접근·이탈, 작업공간·자세 회전 외곽·경로 전체 TCP 도달 반경과 공구 포함 가반을 검사합니다. 가반 35kg, 공구 3kg 등의 숫자는 편집 가능한 예제값입니다. 시간은 경로 길이/속도+집기/놓기 시간입니다. **관절·IK·전체 링크 충돌·토크·흡착 및 포장 변형은 계산하지 않습니다.** 그리퍼 근사 통과를 실제 로봇 실행 가능성 전체의 검증으로 표시하지 않습니다.

손상 박스는 격리, 누락은 별도 기록, 규격 오인식은 관측 치수로 미확정 패턴을 다시 계산합니다. 정상 박스의 검토 위치가 없으면 그 단계에서 멈추며 다음 미입고 상자를 먼저 선택하지 않습니다. 전체 재고 재정렬·무게 규칙 끄기·그리퍼 제외·이전 평가 정책은 별도 연구 조건입니다.

## 실험과 검증

웹 연결 전에 변경하지 않은 혼합 박스 3세트 × 3정책과 동일 과제 제약의 기존 Greedy를 실행했습니다. 새 BL/Greedy/Rollout은 각각 7/8/7개(30개 입력), 10/8/8개(24개), 6/6/6개(24개)입니다. 새 정책이 모든 입력에서 적재 수를 개선하거나 Rollout이 항상 좋다는 결과는 없습니다.

처음에는 기존 기둥 비율 하드 제한만으로 7919 입력 첫 상자가 막혔습니다. 접촉 여유 검사와 분리해 보완했고, 안정성이 부족한 긴 상자는 계속 거절됩니다. 입력·실패 단계·측정 시간과 전후 실행을 [보고서](docs/ONLINE-MIXED-PALLETIZING.md)와 [측정 JSON](docs/pallet-online-measurements.json)에 보존했습니다.

## 임시 보류와 상단 복귀

전체 재고 선택 / 낮은 빈자리 전략에서는 다음 박스가 잔량의 자리를 막을 때 외부 대기대 1자리에 보류합니다. 다른 박스를 적재하는 동안 상단 복귀 가능성을 매번 확인합니다. **임시 보류 예제** 버튼으로 단계별 대기·회수를 확인하고, **탐색 범위 · 점수 가중치 → 임시 보류 후 상단 복귀**로 켜고 끕니다. 이미 적재한 박스를 빼지 않으며 버퍼 없는 순차 입고에는 적용하지 않습니다. [검증과 한계](docs/TEMPORARY-BUFFER.md).

## 4대 로봇 협업

상단 **4대 로봇 협업**은 독립 동시 실행입니다. 각 로봇이 자기 작업을 수행하고 끝난 팔부터 다음 작업을 계산합니다. 방해 박스를 전달대에 내려놓으면 옆 팔이 자신의 상황을 검사하여 **전달대 → 팔레트 직접 적재** 또는 **전달대 → 자기 대기 재고 보관**을 선택합니다. 공유 전달대/겹치는 운반 경로만 서로 기다립니다.

**4대 전달 예제**와 **회수 후 보관 예제**로 두 분기를 재현할 수 있습니다. **준비된 팔 함께 시작**은 현재 실행 가능한 팔의 작업을 함께 시작하고 추가 작업은 자동 시작하지 않습니다. **4대 자동 실행**은 끝난 팔에 새 작업을 계속 줍니다. 기본 4배속이며 일시정지·미확정 동작 취소·완료 이력·JSON 저장을 지원합니다. 취소 후 이미 완료된 적재와 전달대 박스는 유지합니다. [동시 알고리즘과 한계](docs/FOUR-ROBOT-CONCURRENT.md).
