# 혼합 적재 워크스페이스

## 사용 흐름

1. **시험 조건**에서 공개 데이터 프로필·박스 수·시드·팔레트 규격·화물 높이·허용 화물 중량을 정하고 **조건 적용·시작**을 누릅니다.
2. **배정** 패널에서 네 로봇의 작업과 중앙 배정 이유를 확인합니다. 잔여 부피만으로 판단하지 않고 유효 배치 후보와 관측된 후속 박스의 수용성을 비교합니다.
3. 상단 **지표**를 누르면 3D 옆 검사 패널에 해당 분석이 열립니다. 큰 숫자 → 상세 지표 → 문제 박스 순서로 확인합니다.
4. 3D의 박스를 클릭하면 실행을 일시정지하고 **박스** 패널을 엽니다. 박스 목록 검색도 같은 선택을 제공하며, 선택 박스를 강조하고 다른 적재 박스는 옅게 표시합니다.
5. **이벤트 재생**으로 예약·배치·팔레트 교체·계산 응답 당시 상태를 확인합니다. **현재 시점**은 실제 실행 상태로 돌아오며, 과거 기록을 선택해도 이미 실행한 적재는 변경되지 않습니다.
6. **진단 → 보관 이력 내 최장 판단**을 누르면 해당 계산 응답 시점으로 이동합니다. 국부 지지 진단은 선택 시점의 상부 하중까지 포함한 상태를 보여줍니다.
7. 완료한 실행을 **실행 비교**에서 보관하고, 배정 방식을 바꾸어 동일 입력으로 다시 실행합니다. 조건이 달라지면 비교 화면에서 차이를 명시합니다.
8. **결과 내보내기**는 입력·모델 상태·단계 이력·지표·배정 설명·브라우저 정보를 JSON으로 저장합니다.

기존 단일 팔레트·포장·변형 실험과 설명은 **연구 도구** 메뉴에 보존했습니다. 공정 작업공간에서는 실행 제어와 분석에 필요한 기능을 우선 배치했습니다.

## 화면과 디자인

사용자가 제공한 `DESIGN.md`의 vellum `#f0efe9`, carbon `#322d2a`, paper white, 가벼운 산세리프 글꼴, 평면적인 표면과 절제된 경계를 적용했습니다. 80px 이미지 모서리나 홍보용 대형 제목을 조작 화면에 그대로 옮기지 않고, 시뮬레이터의 면적·가독성과 조작 순서를 우선했습니다. 외부 폰트 요청 없이 로컬 대체 글꼴을 사용합니다.

색상뿐 아니라 정보 구조를 변경했습니다. 여덟 개의 상시 메뉴를 연구 도구로 정리하고, 실행·초기화·속도는 캔버스 위, 이벤트 재생은 아래, 진단·배정·박스·지표는 오른쪽 검사 패널에 모았습니다. 긴 설명·후보 점수·시험 조건은 필요할 때 엽니다. 좁은 화면에서는 검사 패널이 캔버스 아래로 이동합니다.

분석 시점이 기본이며 공장 시설은 선택해서 표시합니다. **입체/평면/전체 보기**로 관점을 바꿀 수 있고, 창 크기에 맞춰 실제 작업 영역을 카메라에 맞춥니다.

## 지표의 범위

- **적재 적합성**: 현재 적재분과 출고 팔레트의 기하·접촉·합성 하중 모델 판정입니다. 전체 로봇 관절·링크와 현장 물리 안전 검증은 별개입니다.
- **적재 성과**: 실제 적재된 박스 수 / 전체 입력 수. 정격 공간 활용률의 분모는 적재된 현재 팔레트와 출고 팔레트 수 × 규격 용적입니다. 비어 있는 셀은 사용 팔레트에서 제외합니다.
- **안정성**: 선택 시점의 국부 지지 경계 여유가 대표값입니다. 세부 `g` 값은 수평 강체·비미끄럼 가정하의 국부 전도 근사이며 전체 화물 운반 안전 지수가 아닙니다. 실측 압축강도는 미검증입니다.
- **로봇 작업**: 모델 경과시간으로 계산한 처리량과 개별 작업 예상시간입니다. 박스 적재 완료는 기존 엔진의 복귀까지 끝난 작업 완료 시점에 반영됩니다. 물리 로봇의 실측 초/박스가 아닙니다.
- **계산 성능**: 최근 최대 10,000개 유효 측정값 중 후보 검토가 있었던 Worker 호출의 P50/P95/P99. Worker 내부 계획시간이며 메시지 전송·렌더링 시간을 포함하지 않습니다. 마감시간 내 유효해 반환율은 별도 계측이 없어 미검증으로 둡니다.
- **강건성**: 자동 반복 순서·예외 주입 시험이 연결되지 않았으므로 미검증입니다. 단일 실행의 재순환 횟수를 복구 성공률로 해석하지 않습니다.

지표는 같은 물리 단위로 임의 합산하지 않습니다. 배정 점수는 유효 후보의 순위를 정하는 휴리스틱이며 안전 확률이 아닙니다.

## 기록과 계산량

최근 600개 의미 있는 이벤트의 불변 상태를 보관합니다. 애니메이션 매 프레임마다 이력을 새로 복제하지 않습니다. 과거 기록과 현재 실행은 별도이며, 마지막 600개보다 오래된 단계는 3D 드릴다운 대상에서 빠집니다. 배치 전체 기록과 출고 이력은 월드에 남습니다.

지표 계산은 셀 버전·출고 사이클로 접촉/평형 결과를 재사용합니다. 변경된 팔레트의 기하 검사에는 박스 수에 대한 이차 비교와 평형 풀이가 포함되며, 매 화면 프레임마다 같은 풀이를 반복하지 않습니다. 중앙 배정의 연산 범위와 비교 측정은 [알고리즘 문서](central-orchestration.md)에 있습니다.

브라우저 배속과 렌더링 일정에 따라 집기 기회가 달라질 수 있습니다. 반복 재현 가능한 정책 비교에는 고정 시뮬레이션 시간 간격의 테스트를 사용하고, UI 비교에서는 장비·브라우저·배속을 고정해야 합니다. Arduino 성능을 브라우저 시간에서 환산하지 않습니다.

## 공개 데이터와 출고 해석

기본 입력은 BED-BPP 원본 주문들을 연결한 120개 용량시험입니다. 원본 한 주문을 재생하거나 기존 합성 입력으로 전환할 수도 있습니다. 원본 주문 내 치수·중량·순서는 보존하며, 네 로봇 셀로 재생하므로 공식 BED-BPP 리더보드 실험과는 다릅니다. 팔레트 높이·마찰·그리퍼·지지 기준은 시뮬레이션 조건이며 출처가 제공하지 않는 압축강도를 만들어 넣지 않습니다.

화물 높이는 적재면부터 측정합니다. 팔레트 두께를 입력해야 바닥 기준 총높이 상한이 표시됩니다. 허용 화물 중량은 팔레트 자체 중량을 제외하며, 설정 시 후보 검사와 결과 평가 모두에 적용합니다. 미입력 값은 미설정으로 표시합니다.

팔레트 이력에는 입력 종료에 따른 잔량 출고, 높이 상한 근접, 제한된 탐색에서의 후보 소진을 구분합니다. 후보 소진은 수학적으로 더 이상 적재할 수 없다는 증명이 아닙니다. 입력 총부피/빈 팔레트 네 장의 용량은 시험 부하의 크기이며 실제 공간 활용률과 다릅니다.

R4가 적게 움직이는 것은 낮은 투입 부하와 상류 우선 배정에서 발생할 수 있습니다. 기본 **처리 효율 우선** 외에 **작업 분산 우선**을 선택할 수 있으나, 분산하면 완료시간·사용 팔레트 수가 증가할 수 있습니다. [현실적인 시험 설계와 무게중심 검증](realistic-trials.md)을 참고하세요.
