# PAC2026 로보틱스 해커톤 — 이어가기 폴더

정리일: 2026년 10월 9일, 한국 시간.

현재 대화에서 확인할 수 있는 논의 흐름과 작업 폴더에 남아 있는 개발·실험·조사 자료를 함께 보존했다. **대화 원문 전체를 내보낸 파일은 아니며, 대화 요약과 기존 파일의 복사본이다.** 기존 프로젝트는 수정하지 않았다.

## 지금 어디까지 왔는가

**최신 사용자 결정(2026-10-09): 가벼운 물체 위에 무거운 물체를 놓는 배치를 상대 중량만으로 금지하지 않는다.** 실제 지지·허용하중·취급 조건은 별도 검증한다. [중량 순서 제약 결정](01-대화-흐름과-결정.md)을 우선 참고한다. 이번 갱신은 기록만 반영했으며 코드·실험 조건 변경은 아직 수행하지 않았다. 아래 기존 요약은 작성 당시의 논의 상태다.

목표는 HD현대로보틱스 미션 1의 불확정 순서 혼합 적재를 대상으로, **누구의 어떤 불편을 줄이는지 설명하고 동일 조건 실험으로 뒷받침할 수 있는 솔루션**을 만드는 것이다. 시뮬레이션은 그 주장을 검증하고 보여주는 수단이다.

- 팔레트 절감, 판단 대기 감소, 현장 변동 대응의 세 방향은 모두 열어두었다. 팀 최종 선택은 아직 없다.
- 세 방향의 최소 실험을 완료했다. 새 합성 입력에서 Greedy 대비 팔레트 절감은 입증하지 못했다. 50ms 일괄 예산 축소는 정상 물량 미처리를 만들었다. 변동 후 처리·중단 구분은 기능으로 확인했다.
- 공개 산업 사례를 조사했다. 포장 후 예측하기 어려운 순서로 도착하는 박스를 적재하는 문제는 실제로 존재한다. 기존 상용 제품도 이미 혼합 적재와 재계획을 제공한다.
- 최신 제안은 **한 출하 적재 셀을 고객 문제로 좁히고, 기본 온라인 적재 비교에 관측 규격 변경 사건 하나를 추가하는 것**이다. 아직 팀 합의나 현장 고객 검증을 거친 결정이 아니다.
- 제공 자료 외에 멘토나 주최측이 특정 현장·제품·사건을 설명한 내용은 없다고 사용자가 확인했다.
