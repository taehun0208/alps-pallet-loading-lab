# PAC2026 미션 1: HD현대로보틱스 공개 자료로 확인한 현장 맥락

조사일: 2026-10-08 (Asia/Seoul)

목적: “왜 기업이 순서가 불확정한 Mixed Palletizing 문제를 냈을까?”를 공개 근거와 가설로 나누고, 해커톤에서 검증할 공정을 좁힌다. 웹에서 직접 확인한 주최사 공식 자료 네 건을 사용했다. 고객 인터뷰, 내부 출제 배경, 현장 정지 기록은 확보하지 않았다.

## 먼저 확인된 사실

### 1. 적재 패턴 자동 생성은 이미 주최사의 제품 기능이다

HD현대로보틱스의 HRPal은 적재 패턴과 로봇 Job 프로그램을 생성하고, 팔레트·패키지·간지 정보를 이용하며 적재 위치·순서·방향을 조정한다. 소개에서는 설치와 시운전 검토도 강조한다. 따라서 “박스 좌표를 자동으로 계산하고 3D로 보여준다”는 설명만으로는 기존 제품과의 차이가 드러나지 않는다. [공식 HRPal 제품 페이지](https://www.hd-hyundairobotics.com/biz/product/support/287)

- 출처 성격: 로봇 제조사의 1차 제품 설명.
- 한계: 순서 미공개 온라인 입력, 손상·누락 시 재계획 등의 지원 여부는 공개 설명만으로 판단할 수 없다. “HRPal은 혼합 박스를 처리하지 못한다” 또는 “반드시 사람이 매번 재프로그래밍한다”는 결론을 내려서는 안 된다.

### 2. 혼재 규격과 중량물 취급의 어려움은 실제 고객 사례에서 확인된다

공식 사례는 HD현대일렉트릭 중저압차단기 생산동에서 무겁고 여러 규격인 컨테이너를 3D 스캐너와 로봇으로 하역하고 반송하는 공정을 설명한다. 규격이 일정하다는 전제에서 벗어나면 자동화가 어려워지고, 높은 적재물과 중량물은 작업자의 대응에 부담을 준다고 명시한다. [공식 다품종 동시 디팔레타이징 사례](https://hd-hyundairobotics.com/application/robot-solution/38)

- 출처 성격: 공급사가 고객과 공정을 명시한 적용 사례. 현장 존재에 대한 근거는 있으나 고객 독립 평가 자료는 아니다.
- 한계: **디팔레타이징(하역) 사례이며 이번 온라인 팔레타이징(적재)의 성과 증거는 아니다.** 주최사 페이지에는 Mixed Palletizing 기술도 소개되어 있지만, 해당 라인의 임의 순서 적재 성능이나 실패율은 공개하지 않는다. “기업에 아직 혼합 적재 기술이 없다”는 주장은 부적절하다.

### 3. 주최사의 물류 사업 방향은 현장별 검증 후 확대 적용에 가깝다

2026-01-16 HD현대로보틱스·HD현대마린솔루션 MOU는 물류 시스템 자동화, 현장에 맞는 기술 검토, 물류센터 시범 운영과 PoC를 단계적으로 진행한다는 내용이다. 목표는 물류 처리 안정성과 운영 효율 개선이다. [공식 MOU 보도자료](https://hd-hyundairobotics.com/company/news/6032)

- 출처 성격: 협약 당사자의 1차 보도자료.
- 한계: 실행 계획과 기대 효과이며 성과 보고가 아니다. 이 협약이 PAC2026 미션 1의 직접 배경이라는 증거도 없다.

### 4. 팔레타이징의 상업적 쓰임은 팔레트 개수 외에도 있다

공식 응용 페이지는 물류·유통·식음료·제약·소비재 제조를 적용 분야로 들고, 제품 정렬·적재·하역·이동·보관을 함께 설명한다. 중량 작업 부담과 생산성·안전성을 개선 대상으로 제시한다. [공식 팔레타이징 응용 소개](https://hd-hyundairobotics.com/application/4)

- 출처 성격: 제조사 응용 마케팅 자료.
- 한계: 소개된 생산성·불량률·원가 개선 수치는 특정 혼합 적재 알고리즘의 독립적인 효과로 확인되지 않는다. 이를 우리 솔루션의 기대 절감률로 가져오지 않는다. 해당 페이지의 수치를 뒷받침하는 원 사례집의 대상 공정·분모·조건은 이번 조사에서 검증하지 않았다.

## 출제 의도에 대한 해석: 확인 사실이 아닌 추론

사용자 제공 심사표는 과제 1에서 순서 미공개 실시간 계획, 안정성과 공간 효율의 균형, 재계획 속도와 시뮬레이션 검증을 함께 본다. 배점은 문제 정합성·기술 성숙도·현장 적용 가능성·사업화/실증 연계·기업 도입 의향 각각 20점이다. 이것은 적재율 단독 경진대회로 읽기 어렵다.

앞선 공식 자료와 이 조건을 종합하면, **정해진 패턴을 반복하는 자동화를 넘어 실제로 도착한 물품과 현재 쌓인 상태에 따라 실행 가능한 다음 배치를 정하는 능력**을 평가하려는 것으로 해석할 수 있다. 이는 내부 출제자에게 확인한 설명이 아니라 공개 조건에서 도출한 가설이다.

특히 “혼합 품목”과 “투입 순서 불확정”은 다르다. 주문별 품목과 수량을 안다고 해도 최종 도착 순서를 바꿀 수 없다면, 전체를 미리 배치하는 계획과 실제 실행 사이에 차이가 생긴다. 이 차이를 해결하려면 가능한 대응(대기·재정렬·추가 버퍼·새 팔레트·즉시 적재)의 권한과 비용을 먼저 정해야 한다. 현장에 이 대응이 실제로 얼마나 필요한지는 별도 확인 대상이다.

## 해커톤 타깃 공정 제안 — 검증 전 후보

**공장 출하 구역 또는 물류센터에서, 주문별 혼합 박스가 하나의 투입 컨베이어로 들어오며 주문 목록은 알지만 순서를 보장하기 어려운 적재 셀**을 우선 후보로 둔다. 실제 특정 HD현대 고객 공정이라고 단정하지 않는다.

| 구분 | 제안하는 범위 | 아직 확인해야 할 것 |
|---|---|---|
| 직접 사용자 | 적재 셀을 설정·시운전·운영하는 자동화 엔지니어 및 작업자 | 실제 예외 대응 담당자와 승인 권한 |
| 도입 판단자 | 현장 물류/생산기술 책임자, 로봇 시스템 구축사 | 구매 주체와 비용 배분 |
| 단일 문제 가설 | 계획 순서와 실제 투입 순서가 다를 때, 추가 재정렬이나 보류 없이 유효한 적재를 이어가기 어려움 | 이 문제가 반복되는지, 현재 대응이 무엇인지 |
| 입력 가정 | 박스 목록·규격·중량, 도착한 박스 ID, 현재 적재 상태 | 센서 정확도, 상태 갱신 주기 |
| 출력 | 다음 배치/실행 불가 사유/허용된 대체 행동 | 실시간 전달 방식과 로봇 제어기 연결 |
| 좁힐 범위 | 하나의 셀과 동일한 버퍼·팔레트 조건에서 순서 변동 대응 | 실제 재정렬 가능 여부, 버퍼 크기, 팔레트 병행 수 |

추천하는 1차 실험은 같은 주문 목록에 투입 순서만 바꾸고, 같은 제약을 준 비교 방식과 제안 방식을 평가하는 것이다. 대표 지표 후보는 **정상 박스를 제외하지 않고 처리한 작업의 비율/추가 보류 횟수**이며, 팔레트 수·응답 시간·안정성 제약 위반을 함께 본다. 실제로 공정이 멈추는 모델이 없다면 “라인 정지시간 감소”라고 이름 붙이지 않는다.

이 후보가 좋은 이유는 미션 조건과 바로 연결되고 기존 시뮬레이션으로 비교를 시작할 수 있기 때문이다. 이 현장 문제가 가장 비싸거나 시급하다는 뜻은 아니다. 현장 담당자가 순서를 쉽게 통제할 수 있거나 기존 설비가 잘 처리한다면 후보를 바꿔야 한다.

## 발표 전에 출제기업에 확인할 질문

1. 순서를 모르는 이유가 무엇인가: 여러 라인의 합류, 피킹 순서, 상류 하역, 주문 변경 중 어느 상황인가?
2. 현재는 순서를 다시 맞추나, 버퍼에 두나, 새 팔레트를 여나, 작업자가 직접 판단하나?
3. 실제로 가장 부담스러운 것은 보류 물량, 작업 중단, 재적재, 팔레트 증가 중 무엇인가? 최근 사례 하나가 있는가?
4. HRPal 또는 현재 사용하는 계획 방식과 비교할 때 이번 과제에서 더 필요한 기능은 무엇인가?
5. 버퍼 개수, 동시 사용 팔레트 수, 이미 쌓은 박스의 재배치, 최대 판단 시간은 각각 어떻게 제한되는가?
6. PoC를 한다면 어떤 박스 목록·투입 기록·실패 기록을 제공할 수 있고, 어느 결과면 다음 실증으로 넘어가겠는가?

## 발표에서 피해야 할 주장

- “현장은 모두 손으로 적재한다”: 주최사 자체 자동화 제품과 고객 사례가 있다.
- “우리가 혼합 적재를 처음 해결한다”: 공식 자료부터 혼합 규격 대응을 제공한다.
- “팔레트 감소 = 운송비 동일 비율 감소”: 트럭 적재 한계·중량·출하 단위·회송 조건을 확인하지 않았다.
- “안전 제약 통과 = 실제 운송 중 붕괴 없음”: 마찰·상자 변형·진동·랩핑 등 실물 조건은 별도 검증이다.
- “예외 처리가 있으니 사람의 개입이 줄었다”: 기존 대응과 실제 개입 기록이 필요하다.
- “출제 의도는 이것이다”: 현재는 공개된 과제 조건을 해석한 것이다.
