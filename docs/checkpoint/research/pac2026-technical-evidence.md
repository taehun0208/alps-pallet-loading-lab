# PAC2026 기술 실현성 추가 검증: 미션 1과 3

확인일: 2026-09-23. 이 문서는 대회 원문 요구사항을 재정의하지 않고, 독립적인 1차 자료로 기술적 판단을 보충한다. 팀 역량·산업 장비·전용 데이터가 확보되지 않은 상황을 가정한다.

## 확인된 사실

1. **온라인 혼합 적재는 공개 연구와 구현이 있는 문제다.** ICLR 2022 PCT 공식 구현은 연속 크기 상자와 컨테이너, 근사 안정성 검사, 휴리스틱 비교군, 학습 중 생성 데이터 및 사전 학습 모델을 제공한다고 설명한다. 저장소는 MIT 라이선스를 표시한다. 공개 코드를 직접 실행해 검증하지는 않았으며, 구형 Python/gym/PyTorch 권장 환경으로 인한 이식 작업이 생길 수 있다. [PCT 공식 저장소](https://github.com/alexfrom0815/Online-3D-BPP-PCT)

2. **공간을 채우는 성능과 실제 로봇 실행 가능성은 별도 평가가 필요하다.** RoboBPP는 물리 시뮬레이터, 산업 유래 데이터 3종, 수학적 적재·물리 제약·로봇 실행을 구분한 평가를 제안한다. 저자들은 중력·마찰·동적 안정성과 실제 데이터 분포를 무시한 실험의 전이 한계를 지적한다. 2026-04-07 개정 arXiv 원문은 IJRR 심사 중으로 표시되어 있으므로 확정된 동료심사 결과로 취급하지 않는다. [원문](https://arxiv.org/abs/2512.04415), [공식 프로젝트](https://robot-bin-packing-benchmark.github.io/)

3. **모든 공개 구현을 자유롭게 제품화할 수 있는 것은 아니다.** AAAI 2021 Online-3D-BPP-DRL 저자 저장소는 학술 용도 한정 및 상업 사용 별도 허가를 명시한다. 학습 데이터 분포에 따라 성능이 달라지고, 안정성 제약 완화로 적재율을 높여도 실제 사용에 문제가 될 수 있다고 설명한다. [공식 저장소](https://github.com/alexfrom0815/Online-3D-BPP-DRL)

4. **WPS는 단순 재질별 전류 추천표가 아니다.** TWI는 WPS가 용접 품질과 기계적 특성을 위한 용접 변수를 규정하며, 관련 승인 기록은 용접 기록·비파괴 검사·기계적 시험 등을 포함한다고 설명한다. 중요 변수에는 재질, 용접 공정, 두께 범위, 경우에 따라 자세가 포함된다. [TWI: Welding procedure](https://www.twi-global.com/technical-knowledge/job-knowledge/welding-procedure-039)

5. **이음부 조건과 준비 상태도 중요하다.** TWI는 접합 준비에 이음 종류, 개선 형상, 이음 치수와 표면 세정이 포함된다고 설명한다. 따라서 재질 표기 사진 하나가 모든 용접 조건을 제공한다고 볼 수 없다. [TWI: Surface preparation](https://www.twi-global.com/technical-knowledge/faqs/faq-what-is-surface-preparation-for-joining)

## 위 사실에서 도출한 판단 — 대회 공식 평가가 아닌 제안

**미션 1의 장점:** 최소한 상자 치수·무게·허용 회전과 팔레트 치수가 주어진다면 실제 산업 이미지 없이도 알고리즘을 구현하고 동일 시퀀스로 비교할 수 있다. 입력 순서를 미리 아는 오프라인 알고리즘을 온라인 결과처럼 비교하지 않는 것이 핵심이다. 기본 휴리스틱→안정성/적재 하중 제약→제한된 선행 정보 또는 버퍼→물리 검증 순으로 확장하면 성과를 단계별로 입증할 수 있다. 대회가 완전 무선행인지, lookahead나 버퍼를 허용하는지는 원문과 운영 측 확인이 필요하다.

**미션 1에서 배울 도메인:** 온라인 3D bin packing, 높이맵/빈 공간 후보, 지지면과 무게중심, 상자 하중/압축 한계, 로봇 도달성·그리퍼 여유·충돌, 치수 오차. 지지면 비율 하나만으로 물리 안정성 전체를 검증했다고 주장하면 안 된다.

**미션 1에서 추천할 구체 범위:** '무작위로 들어오는 박스에 대해 적재율과 안정성을 함께 최적화하고, 불가능한 배치를 설명하는 온라인 적재 의사결정기'. 고정된 무작위 시드의 다양한 입력 순서에서 적재율, 배치 불가율, 안정성 위반/붕괴율, 결정 지연을 함께 보고한다. 강화학습부터 시작할 필수성은 없다.

**미션 3의 장점과 병목:** 사진→표기 추출→재질/두께 정규화→기존 조건 후보 검색은 소프트웨어 시연 범위가 뚜렷하다. 그러나 OCR 정확도와 적절한 용접 조건 추천의 정확도는 다르다. 표기에서 빠진 공정·자세·이음/개선 형상·소모재/장비 조건은 추가 입력 또는 생산 정보 연동으로 보충해야 한다. 승인된 WPS나 검증된 조건 DB가 없는 상태에서 그럴듯한 숫자를 생성하면 정답 검증 자체가 막힌다.

**미션 3에서 배울 도메인:** 소재 등급/표기 체계, OCR 오독과 단위 정규화, WPS/PQR의 역할과 적용 범위, 공정·자세·이음 형상·두께·용가재/보호가스·예열 등 조건 변수. 모든 변수가 사진에서 추출된다는 가정은 피한다.

**미션 3에서 추천할 구체 범위:** '판독 신뢰도와 누락 조건을 보여 주고 검증된 WPS 후보 및 근거를 검색하는 도우미'. 범위를 한 재질군·한 공정·제한된 이음 형상으로 줄이고, 미일치 시 추천 보류를 명시한다. 조건 DB가 대회에서 주어지고 이 범위가 요구사항과 맞는다면 빠른 완성에 유리하다. DB와 전문가가 없다면 미션 1보다 해결 확실성이 높다고 단정할 수 없다.

## 선택 기준

- 데이터·장비 미확보, Python/최적화 구현 가능: 미션 1의 알고리즘+시뮬레이션 결과가 상대적으로 검증하기 쉽다.
- OCR/서비스 개발 강점, 제공되는 실제 표기 이미지와 검증된 조건 DB 또는 용접 멘토 확보: 미션 3이 유력하다.
- 실물 로봇 통합이 평가 필수라면 두 주제 모두 장비/API/시험 기회가 선택의 선결조건이다.
- 어떤 주제도 수상이나 산업 적용 성공을 보장할 수 없다. '확실성'은 범위를 줄인 MVP를 객관적 지표로 검증할 수 있는 정도로 해석한다.
