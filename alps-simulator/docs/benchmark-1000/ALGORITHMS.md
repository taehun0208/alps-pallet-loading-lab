# 비교 알고리즘의 내용과 검증 범위

이번 비교는 같은 엔진 위에 구현한 온라인 정책들이다. 이름이 유사한 논문·상용 솔루션의 완전 재현이나 그 제품 대비 우위를 의미하지 않는다.

| 정책 | 실제 선택 방식 | 잔량 이용 | 비교에서 확인할 것 |
|---|---|---|---|
| Bottom-Left-Back | 물리 검사를 통과한 후보 중 z→y→x | 없음 | 낮은 면부터 채우는 빠른 기초선 |
| Compact | 가장 낮은 면, 접촉·공극의 기존 Compact 점수 | 미래 순서 예측 제외 | 단순 공간 밀집 휴리스틱 대비 개선 |
| Greedy | 현재 후보의 가중 특징 점수 | 공통 점수의 잔량 특징 | 기존 프로젝트의 탐욕 정책 대비 개선 |
| Lookahead | 잔량에서 가상 후속 입고를 만들어 짧은 탐색 | 있음 | 작은 미래 탐색 대비 품질·비용 |
| Future Hybrid | 여러 미래 손실·예약 항을 결합한 프로젝트 정책 | 있음 | 강한 미래 고려 정책 대비 품질·비용 |
| ALPS Tetris | 낮은 z·적은 신규 공극 등 사전식 비교 후 최대 6후보×3시나리오×4미래박스 rollout | 있음 | 지형·빈틈 확장과 짧은 예측의 결합 효과 |
| ALPS 군집·연결 우선 | 바닥·신규 공극을 먼저 고려하고 동일 SKU·구역의 접촉을 우선 | 잔량 규격으로 틈 평가; Tetris rollout 없음 | 물량과 공간을 유지하면서 군집을 개선하는지 |

일반 후보 상한은 48개다. ALPS 두 정책은 기본 후보 외에 128개 상한의 후보와 추가 경계·틈 좌표를 검사한다. 입력·물리 제약·전체 시간 한도는 공통이지만 후보 수나 연산량이 같은 절제 실험은 아니다. 따라서 빠른 계산과 품질은 함께 보고하고, 특정 구성요소의 인과 효과는 별도 ablation 없이는 주장하지 않는다. 모든 정책은 공통 BLB 유효 후보를 먼저 확보하는 동일 실행 래퍼를 거친다.

MCTS는 별도 UCT 선택·확장·rollout·역전파를 수행한다. 사용자가 2시간 내 신속 결과를 요청하고 제외를 명시했기 때문에 이번 본 비교에서 뺐다. 과거 기록과 코드는 삭제하지 않았다.

## 관련 원논문과 차이

- [Crainic·Perboli·Tadei, Extreme Point-Based Heuristics](https://www.cirrelt.ca/documentstravail/cirrelt-2007-41.pdf): 극점 기반 후보 생성이라는 관련 개념. 현재 구현은 경계·기존 상자 좌표 교차와 상부 착지 높이를 쓰는 변형이며 EP-FFD/EP-BFD를 그대로 재현한 결과가 아니다.
- [Wang·Hauser, Robot Packing with Known Items and Nondeterministic Arrival Order](https://motion.cs.illinois.edu/papers/TASE2020-Wang-RobotPackingNondeterministic-preprint.pdf): 물품 집합을 알되 도착 순서를 모르는 문제와 관련된다. 현재 구현은 모든 미래 순서에서의 적재 가능성을 인증하는 QOP가 아니다.
- 정적 평형의 관련 문헌과 자체 검사 범위는 [기존 알고리즘·물리 모델 설명](../ALPS-TETRIS-알고리즘과-물리모델.md)을 따른다.

이 실험에서 허용되는 결론은 “정해진 합성 입력·시간 예산·공통 제약·검사한 정책들 사이에서 나타난 효과”다. 전역 최적 알고리즘, 산업 전반 최고 효율, 실제 현장 비용 절감으로 바꾸어 말하지 않는다.
